# 制作交接与正式运行规则

适用：项目固定 Profile 的 `contract_policy` 为 `production-v2`。契约字段以 [contracts.json](contracts.json) 与各模板为准；本页定义这些契约之间的使用规则。旧作品继续使用自己的固定快照，不会因插件更新自动升级。

## 故事与覆盖

来源登记保存固定快照、完整 SHA 和原工作路径。原文件移动或修改不会重写已登记依据；快照损坏则阻断。来源单元引用 `source_id`、`source_sha256`、可解析 `locator`，并区分事实、人物说法、解释和改编。新增叙事单元使用 `origin: invention` 与针对该产物的真实 accepted invention 决策，不编造出处。文本支持行范围，JSON 支持 pointer；无法解析页码或时间码时只能如实绑定整文件 SHA，不能宣称检查过某一页。

剧本保留自由正文，另列场次、行动、对白、静默、预计时长和改编单元引用。单条结尾可选择闭合、余韵、行动或悬念；不强制每条短视频悬念收尾。分集节拍绑定具体改编版本。

覆盖计划枚举 scope 下的场、sequence、镜头，并绑定剧本、镜头和声音计划版本。遗漏必须绑定针对真实对象的 accepted omission 决策。新场次、镜头或剧本版本会使旧清单需要复核；有清单不代表导演已经认可表达效果。

## 素材与声音

稳定资产 ID 与绑定版本分开。更新用 `object bind`，保留历史；消费者登记时固定实际引用的资产版本。变体只使用对应用途的参考，音频、视频、图像引用保留各自角色。姿态、朝向、视线与持物手进入状态及关键帧提示。

连续性消费明确的获选集合和剪切策略。只有 match_frame 要求相同首尾帧；其他策略检查声明的状态字段。没有选择的多候选是歧义，输入顺序不能代替选择。声音与视觉锚点分别计算；修改音色不会改变静音图像的视觉锚点。已有文件可经新一轮固定版本审阅复用，不自动要求重新生成，也不自动批准旧候选。

`selected-takes` 绑定 take、原生成记录或手工导入、输出 ID、文件 SHA、用途、权属、范围与选择人。成功生成记录可以是 draft；**获选清单的真实批准**才是进入正式剪辑的选择。临时、未知权属素材不能正式选用。

对白 Cue 回指固定剧本行 ID，记录人物、台词、表演选择及口型用途。声音候选记录实测时长；时间线核对所选表演与 Cue。原生音画对白保留真实审听／口型复核负责人；系统不会推断“口型已经正确”。混音逐项核对计划 Cue、实际音轨覆盖与 J/L cut 边界。

## 正式运行与共享预算

`production-run` 是可审阅产物；计划 hash 只是防漂移凭据。执行需该产物真实批准、明确的批准输入、相应 Gate、固定请求参数和项目共享额度。图像／视频批次仍使用现有队列的拓扑排序、输出验证与恢复机制。

`phase: asset` 先核对 script Gate 与批准资产规格，只制作资产图或单次声音／检查请求，避免要求资产先完成依赖它的预演。`phase: production` 核对 animatic Gate 与批准预演，才制作镜头候选。不能用资产准备阶段绕过镜头预演。

生成结果被下游使用前需声明人审暂停点。成功先导入 draft，保留 `selection: null`；真实审阅绑定 run 和输出 SHA。拒绝或旧版本审阅不能放行新输出。恢复查询原任务，不重复付费提交；缺任务编号且提交不明则停止。

项目预算按 `remote_jobs`、`images`、`video_seconds`、`speech_chars`、`audio_jobs`、`vision_jobs` 管理。每个 run 的所有预留原子写入；多个批次、声音、视觉检查共用同一账本，并按集、镜头／台词及状态汇总。失败、弃用或提交不明仍保留占额；平台用量和币种金额未知时明确为未知，不能用本地成功反推账单。手工结算需真实用量证据，不能消除已经提交的请求次数。

## 后期与交付

时间线包装已有 Remotion 帧语义，每个媒体段回指获选 item 和 SHA；裁切、音频用途与声音 Cue 一并核验。QA 绑定外层时间线文件 SHA。完整解码有时间上限；缺工具、超时、损坏负载、音轨缺口、目标响度不符均不显示通过，合法静默保留。

审片绑定成片 SHA、可解析帧范围、实际镜头／片段与 delivery ID。旧文本意见仍可读取，但正式交付需要完整范围的结构化审片。程序只检查记录和定位，人的判断仍由具名责任人负责。

字幕烧录、剪映和 Remotion 共用样式解析与安全边距；严格 SRT 不静默跳过损坏、倒序、重叠或越界块。剪映当前仅支持 24/25/30 整数 fps，其余明确拒绝；保留计划尾黑场和丢弃／降级说明。Remotion 工程固定原计划、字体与样式 SHA；真实浏览器渲染仍须执行和回看。

交付清单分别绑定各版本成片、字幕、规格、时间线、混音、QA 与审片。可迁移包仅复制明确列入的媒体、工程文件及依赖产物快照，使用相对路径和 SHA 清单；不自动复制私有原文。未授权归档的来源只保留 ID／SHA／权属，来源重验显示未检查。移动后的包重新检查媒体、选择、对象映射与完整技术 QA，不以旧机器上的绝对路径报告冒充新检查。

## 迁移与审阅

`profile migrate` 先输出差异、受影响产物与计划 SHA；应用时核对最新 revision、真实负责人和理由并备份。历史批准和快照保留，失效由新 Gate 如实报告，不自动补批。

轻量单条 Profile 减少重复的来源摘要、分集节拍和视觉说明交付，但保留可核对的核心链。`artifact decide-bundle` 支持一次审阅明确列出的 `ID:SHA` 版本，任何版本失效则整包不写入批准；它不是自动批准工具。返工影响报告只读，实际变更继续登记新版本。
