# 数据库变更交接

用于查询、结构或数据迁移任务，仅填本次适用项；不另建批准或完成台账。纯查询分析不强制全库迁移/备份。

- 目标环境/连接类别、实际服务/驱动版本与schema revision（不含凭据）：
- 应用消费者、表粒度/键/约束或固定查询/参数/分页语义：
- 事务拥有者、锁顺序、并发冲突与恢复：
- 同夹具规模、SQL/行数、计划及应用等待；测量条件：
- 实际变更、兼容影响、原schema专项引用：
- 适用的迁移/备份/恢复步骤与实际比较；不适用理由：
- 正常/失败/并发验证、实际命令与证据；自检或独立复核：
- 未验证范围、交接给应用的要求及保全新事实的回退位置：
