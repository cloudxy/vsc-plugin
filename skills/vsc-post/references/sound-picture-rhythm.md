# 声画节奏：用同一素材做有理由的修改

以下全为原创教学练习，不是已批准作品或默认镜头参数。固定剧本、素材、对白、时长和授权，先做一项可观察的修改；听不出改善就保留原剪法。参考：Yale Film Analysis 的 Editing/Sound，以及 Blackmagic《The Editor’s Guide to DaVinci Resolve 20》印刷185–191页的独立声画切点教学。借鉴原理，不随包分发课程媒体。

## 同题交接：修改说明和真实预览 <a id="edit-result"></a>

**固定题目。** 原创合成任务：12秒“归还钥匙”片段已有底片、独立字幕与音轨，用户要求“把8–10秒的『物归原处』字幕抬高，其他不动”。任务包固定当前版本、完整 Cue、位置目标与保留项；若目标高度存在影响画面的实质歧义，沿原反馈入口收敛，不猜改整条字幕样式。

**对此用途无效的交付。** 返回“已调整，观感更好了”、新渲染计划或一张改字静帧，就把意见标为解决。它们不能证明实际样片用了新位置，也不能证明其他字幕、声音和切点保留。

**应交付的结果。** 从原底片和固定字幕/音轨修改该 Cue 的位置，沿现有编辑与预览路径登记新候选，在原意见返回可播放版本、对应区间与尚未核项。避免把已烧录字幕的成片当底片再叠一层。计划可作为可编辑结果的一部分，真实预览仍须产出；若只有计划就绪，保持“待生成预览”。

**接收者怎样检查。** editor/remotion-composer 核实际用料和版本；post-reviewer 或本次实际审阅者播放8秒前、整个 Cue、10秒后，并连同全段声音回看，比较目标位置、文字/时码、其余字幕、切点和音轨。播放器打开或解码通过只回答技术问题；位置可见但挡住取钥匙动作时，保留新候选并将具体时码退回后期修订，不因执行成功自动采用。用户选择另一版不抹去本版结果。

**没有媒体时。** 可核对计划差异和用料要求，明确尚未播放，不能写成已完成修改或审片。上游缺底片先回用料/恢复，字幕目标未落实回本次编辑，错人物回更早的资产/制作环节；按原依赖只返工受影响范围。本文提供同题验法，没有附带或宣称完成真实改片。

## 画变声留或先听后见 <a id="sound-bridge"></a>

**要学会什么。** 在同源两镜之间选择一个声音接点，解释观众因此先知道或继续感到什么。适合关联明确的场景；时间跳跃需要断裂时不要硬连。

**输入。** 原两镜、可独立编辑的同一音轨、真实可用handles、当前画面切点、必须听清的台词及总时长。没有可用源区间不补造尾音。

**步骤。** 先听正常剪法→说清声源在故事里属于哪里→只前移入声或延后出声→保持画面切点和其他轨不变→完整听看，核尾字、空间及误导。同一环境底跨镜铺设，不能每镜从头播放。

**示范一。** 原：楼梯镜一切走，钥匙声立刻消失，门内镜重新起同一声。改：保留门内镜画面起点，让原钥匙尾声越过画切，长度从现有handles试听选择。作用是同一开门动作延续；代价是若两镜实际隔了一夜，会误导时间。

**示范二。** 原：餐桌切到走廊后才听见同一句来客问话。改：画面仍在餐桌时先入这句原声，再切走廊；其他内容不动。作用是先看听者反应；代价是来客身份稍后才揭示。不能为此改台词或换声线。

**反例。** 原稿有意在落门声后切到次日寂静，硬切建立时间断层。延续雨声会掩盖这一断层，应保留硬切，不能因“顺滑”判优。

**练习/交接。** 取20–30秒授权素材，只交原版/改版及一个接点理由。原sound-cue-sheet的`boundaries`记录`at_ms/strategy/purpose`及适用Cue；timeline中用真实音轨的起点、trim和handle落地，再检查对白与实际区间。纸面Cue不是已听过的成片。Remotion支持剪辑/音量和淡变；混响、均衡不能写成不存在的参数。

**判断/回退。** 未看说明的人能指出先听到什么、何时确认声源，关键字仍清楚；若误认同时空、丢尾字或重复声源，回到声轨/源区间，保留原版本，不先重生成视频。

## 画外事件与反应 <a id="offscreen-cause"></a>

**适用/输入。** 想让画框外事件改变人物选择，且剧本已允许该事实。固定当前场段、谁能听见、授权声源和反应覆盖；新动机或新事件先回改编/剧本，不靠音效补造。

**步骤。** 用一句话说事件→分开事件发生、人物听见、反应及观众确认的时点→先试同一声源与反应顺序→必要时揭示来源→正常速度检查因果，不把所有画外声当旁白。

**示范一。** 原：人物无缘无故收起文件，随后门把响。改：同一门把声先于收文件动作，画面和台词保留。观众可推知他在隐瞒；代价是悬念从“为何藏”变为“谁来”。声音先后必须有源素材支持。

**示范二。** 原：望着窗外的观察段落配一声钟，说明写“他很孤独”。改：保留钟声与停顿，删除无依据的性格结论；以人物停下手中动作的可见反应描述此刻倾听。代价是情感保持开放，不能承诺观众都读成孤独。

**不适用例。** 已要求交代杯子摔碎，只有碎裂声而画内杯子仍完好；这不满足动作结果。应补可用结果镜/调整剧本，不能把观众想象当物理连续性证明。

**练习/映射。** 给同一两镜标三点：事件声起、可见反应、可选揭示。写回原screenplay行动/声音说明、Cue和shot_plan边界；`narrative_refs`仍来自固定上游，不由教材编造。画外人物仍计声源规格、权利和用量。

**验收/回退。** 未读意图的人能解释谁因什么而行动；若时序、空间或事实误读，先修声音放置/覆盖或返回剧本。保留必要旁白：知识片中的来源说明不能因“只用声音”而删去。

## 在动作中找切点 <a id="match-action"></a>

**先决定为什么连接。** 转场先回答“服务什么”：延续同次动作、建立空间、省略时间、形成对照还是有意断裂？再回答其余四问：上镜最后发生什么；用什么连接；镜头怎样过去；下镜第一眼看什么。把答案写回原相邻镜头/场段设计，不新增必填问卷。另核声音是延续、提前、替换还是刻意静默；画面切换不强制环境底或BGM重启。相机甩动、推拉或穿越只是运动设计，还要说明实际怎样切接。

**先分清接法。** 名称不能替代两侧状态；同一题通常只需选一种有理由的接法，不把转场词表、固定秒数或组合效果当默认。

| 接法 | 两镜靠什么成立 | 不能由此声称什么 |
| --- | --- | --- |
| 动作匹配 | 同次动作在切前/切后的阶段相接，施受者、持物手、方向与关键接触一致 | 相似动作发生在不同地点/年代，不自动成为同一次连续动作 |
| 图形匹配 | 形状、构图或运动形成可说明的联系；物体、时间、空间可以改变 | 圆形灯切圆形钟不证明灯真实变成钟，不能省去必要的时空交代 |
| 遮挡接续 | 前景进入、遮住接缝、移开后的揭示符合选定设计；核轮廓、亮度、速度及方向 | 只有选择全遮挡隐藏剪切时，才要求切点两侧都有全幅遮挡和可用柄；部分遮挡、可见接缝或图形划像按各自目的检查 |
| 有意硬切 | 直接从上镜信息切到下镜信息，动作结果、对照或省略可读 | 不要求相同像素或加叠化；切换本身没有一段跨帧过渡时长，镜头停留另计 |

**动作接续的适用/输入。** 两镜确实覆盖同一次动作；固定施受者、持物手、方向、起止姿态及原源区间。动作阶段不兼容时不强行匹配。

**步骤。** 标准备/接触/结果→找两镜共有的动作区间→选一个切点→检查是否重复或跳过关键接触→再连同声音正常速度看。一次只改切点，不同时改速度、声线和色彩。

**示范一。** 原：广景已将票递到对方手里，近景又从伸手开始。改：在伸手过程中切近景，近景入点跳过已发生的准备，保留接触与接收。作用是同次交接；代价是近景前段舍弃，不能因此虚增可用秒数。

**示范二。** 原：人物抬头结束后才切听者，关键迟疑不可见。改：保留原素材，在抬头将完成时切到现有听者反应。作用是关系变化可读；代价是主体面部停留缩短。若听者反应并非同一时刻，必须说明重组而非声称匹配。

**反例。** 两镜分别用左右手、道具已换位置，没有共有动作阶段。可试反应插镜、有意时间省略或另取覆盖；只加叠化不会修复接触。

**遮挡两镜的原创设计例。** 题目是“窗口归还钥匙已完成，转到同楼走廊”，允许省略离开窗口的过程。上镜先让钥匙落定，再由近镜深色推车从画右向左遮入；下镜同向移开遮挡，第一眼交代走廊门牌和人物位置。若选全遮挡隐藏剪切，只能在两侧真实全遮挡区间内找切点，并检查暗部、轮廓和运动是否接得住。切后仍须给观众足够的空间识别，不能以藏住切点代替叙事可读。

**同题不成立的做法。** 上镜推车只遮半幅，下镜换成亮门框，仍宣称“全遮挡无缝”；再把钥匙落定声复制到走廊，造成第二次归还的错觉。可改为动作结束后直接硬切到可识别的走廊，保留一次钥匙声；若坚持隐藏切，则先核是否有其他真实遮挡区间，缺覆盖再回制作。此例只有设计，没有附带媒体或实测时码。

**区间与边界怎样交接。** 有媒体后固定两侧获选文件/媒体引用与SHA、帧率、实际源入出区间、柄和时间线切点；用原格式说明帧端点口径，并核独立声轨的入出、尾音及是否重复。仅在采用`match_frame`策略时按原规则检查相同交界帧；普通硬切、动作匹配和遮挡切不能一概加上同帧要求。`AR-transition-foreground-wipe`的方向、遮挡柄和识别停留是该配方的具体规格，不是所有转场阈值。没有媒体只写预计设计区间、状态和待核项，不编take、源时码或“已正常速度看过”的结论。

**实现与回退。** 已选素材可剪时先在真实区间做局部剪辑；叠化需两段重叠及实际层次，不能当作动作修复。精确变速须有可用源帧、声音处理方案和已核工具支持；蒙版/跟踪须有真实遮罩或跟踪结果、合成执行者及可回看的输出，不能靠提示词或未声明字段假装完成。缺这些条件可选目的仍成立的硬切、调整区间或补必要覆盖。一体生成两段动作与效果也须先核供应商实际输入/控制支持、参考、时序及原用量，文字“无缝穿越”不是硬控制；若结果另经蒙版/变速加工，如实交代加工和用量，不记为模型一次直接兑现。无需默认把所有路线都做一遍。

**练习/交接。** 同一取放素材剪两版，写“切前一刻/切后一刻”、连接目的、声音选择及损失区间；也可只比较原版与一处可成立的硬切。coverage保留所覆盖剧本单元；continuity写入出状态、handles与bridge；声音沿原Cue落地；timeline用真实`trim_start_in_frames/from_frame/duration_in_frames`等所属格式支持字段，不给未经校验的JSON假参数。无素材时可以交上述两镜设计及替代接法，保持待制作；消费者先核真实媒体/可剪区间，制作后再正常速度声画连播并按需逐帧定位接缝。

**判断/回退。** 连播不重复动作，关键结果可见，方向/道具一致；有意跳切按目标另判。失败先回可用区间/覆盖，缺素材才回制作，不用自动解码成功代替观看结论。
