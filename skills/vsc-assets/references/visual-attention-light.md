# 注意力、色彩关系与世界光源

本教材是资产和机位设计的原创转译。专业背景可读 [Yale 的摄影分析](https://filmanalysis.yale.edu/cinematography/)、[场面设计分析](https://filmanalysis.yale.edu/mise-en-scene/)和 [ARRI 布光手册](https://www.arri.com/resource/blob/83996/409091c612f371b0c68b41d9dcb636db/arri-lighting-handbook-english-data.pdf)。这些资料帮助描述可观察条件；本教材不复制电影画面或课程附件，也不证明供应商支持精确景深、色温、光比或运动控制。此处示范均为设计，尚未执行缩略图盲看、实灯或生成试片。

## 同题交接：规格和实际参考分别完成 <a id="reference-delivery"></a>

沿用原创合成题[归还钥匙](../../vsc-direct/references/blocking-coverage.md#usable-shot)。本轮只需要第二镜南侧视角的台面、钥匙和取物左手适用参考；这是条件示例，本文没有生成或附带参考媒体。

| 本轮任务 | 对此用途无效的交付 | 足以交接的结果与检查 |
| --- | --- | --- |
| 设计钥匙规格 | 只写“复古电影感道具” | 明确铜色、缺口身份、第二镜落台朝向与可变光照；写入原规格，交给参考制作。它是有效规格，不标“参考图已完成” |
| 准备生成用参考 | 给出提示词和一个打不开的图片路径，或套用模板占位图 | 从原登记返回实际图片固定引用，generation-producer 打开核对缺口、视角、状态与用途，再绑定任务输入；批准仍沿原决定 |
| 比较两个合法候选 | 将未采用的一张标为无效并删除 | 对照同一用途说明各自可见信息及缺陷，保留真实选择；未采用但合格的一张仍可支持比较 |

接收者实际读取的应是登记后的媒体，不是规格截图或“图片已检查”的文字。可打开但缺口被遮住时，图片可以保留为其他用途候选，但不能充当本镜的身份/状态依据；适用性按用途重新判断。若错用另一钥匙身份，回资产绑定；若所需角度本就未设计，回镜头/参考用途；已有供应商输出而转存失败，先恢复该尝试，不重新生成。

练习只交现有规格/引用与原任务中的缺项：接收者指出“能设计”“能读取”“能作为本镜输入”“已采用”“已传入请求”各有什么证据。没有媒体时合格答案是交清规格和待制作项，不能靠增加说明文件补齐媒体任务。

## 用清晰范围分配注意力 <a id="focus-attention"></a>

**适用与输入。** 当画面漂亮却看不清关键物，或多处信息争夺注意力时，先决定这一拍必须同时看见什么。输入是固定剧本节拍、实际机位与交付画幅、人物和道具身份、前中后景位置、动作起止。不能先写“浅景深电影感”再把因果藏在虚化里。若本段故意让观众暂时漏看某物，记录揭示时点；隐去信息是叙事选择，不是默认错误。本节为设计规格，实际可读性待预演与媒体核验。

**操作。**

1. 列出必读与可延后信息，例如“看清递出的是旧钥匙，接收者先犹豫再伸手”；区分物件存在、物件身份和表情三种任务。
2. 用三个块面标前、中、后景，将关键脸、手、道具放入可同时读的区域。先以大小、遮挡和明暗组织，再决定清晰范围；不机械要求全部最清楚。
3. 以实际画幅缩成手机预览大小，检查轮廓和接触是否仍在。需要焦点转移时写起点、终点与触发，不只写“拉焦”。
4. 锁定其他因素做一次布局或清晰范围比较；实际输出逐帧查看关键时点并正常连播。焦点设计成立不能证明生成过程中保持了它。

**原创同题示范一：钥匙是否被接住。** 固定条件：两人在维修台交还一把带缺口的旧钥匙；15秒；观众须同时读到缺口与接收者迟疑，不改身份或动作。原设计：同一中景机位，把接收者双眼设为唯一清晰层，递来的钥匙在前景完全虚化。修改设计：同一机位和构图，扩大意图中的清晰范围，使钥匙缺口、交接手与接收者下半脸都可辨；背景货架允许模糊。理由：关键物和反应共同构成因果。代价：背景可能更抢眼、面部美化效果减弱；若当前工具无法维持双层清晰，改为单层安排或必要道具插入镜，另算覆盖，不能报精确光圈已执行。

**原创同题示范二：先发现空位。** 固定条件：静态工具墙，一只钩子空着，人物随后把扳手挂回；12秒；先发现缺口，再看补回。原设计：工具墙每件物体都清楚，但前景大块亮包装遮住空钩。修改设计：保持机位、清晰范围及色彩，将已有包装移至不挡空钩的台下，空钩与相邻扳手形成可见间隔。理由：此题失败来自遮挡，继续加深景深没有帮助。代价：前景层次减少，画面可能更平；若遮挡是剧本故意安排，改揭示时点而非擅移物件。两例处理不同问题，不能合成一次技巧效果统计。

**不适用与反例。** 用极浅焦只拍清指尖，却要求读者辨认远处证件文字，是条件自相矛盾。全景群像可能需要多处同等可读；强调单一焦点会损失关系。运动、声音或延时揭示同样可以引导注意力，焦点不是唯一手段。

**练习与判据。** 同一“归还钥匙”节拍画三个块面构图：关键手在前景、与脸同层、在侧面留白。固定人物、道具、画幅和时长，不添加新装饰。给未看意图者看缩略图，请其指出先看哪里、何处证明物件身份及是否接住。挑一版连成静帧预演，再检查关键物持续可读；这项练习尚待执行。

**实际映射与回退。** [visual-bible](../../../templates/visual-bible.json) 用 `intent/composition` 记注意力与清晰范围意图；[asset-bible](../../../templates/asset-bible.json) 的 `entities[].identity/variants/references` 固定钥匙身份和实际可见侧，`references[].purpose/view` 说明用途。[continuity-plan](../../../templates/continuity-plan.json) 的 `camera.framing` 与角色 `pose/prop` 保存机位和持物状态。模板没有通用光圈或焦点伺服接口，实际控制进入已支持的生成请求/recipe并核对。关键物看不清先修布局/遮挡，再改清晰范围或覆盖；身份漂移回资产，运动中失焦回制作路线，不以首帧清楚宣称整段通过。

## 色彩作为本片内的重复关系 <a id="color-pattern"></a>

**适用与输入。** 当色板只是“冷色忧伤、红色热情”的标签，或相邻镜物件颜色漂移时，先为本片建立可见的重复与例外。输入是批准叙事节拍、资产本色、照明环境、相邻镜和交付画幅；明确哪些颜色属于物件身份、哪些来自光照、哪些可在后期调整。颜色可帮助识别、联系或分离，不是固定人格词典。本节为设计规格，尚无真实媒体色彩一致性或受众识别结果。

**操作。**

1. 从实际任务选择少量关系，如“共用工具都回到同一蓝垫”“唯一未归还票夹保留黄色”。写清观众何时看到重复，何时看到例外。
2. 先画少色块的相邻画面，保持物件本色与事件顺序；把不相关的高饱和块缩小或移位，不能为统一色调重写资产身份。
3. 检查颜色之外还有位置、轮廓、动作或文字依据；灰度预览或色觉差异下，关键因果仍应可读。
4. 固定同一媒体和其他处理做A/B；逐镜核对肤色、重要物件与明暗层次。色板文字通过不等于实际调色或生成已完成。

**原创同题示范一：共同使用。** 固定条件：20秒工作台片段，甲把借用的扳手放回共用蓝垫，乙随后也把螺丝刀放回；二人、原有工具和垫子，目标是看懂共用秩序。原设计：每镜背景包装、服装和蓝垫都同样高饱和，蓝垫只在末镜出现。修改设计：保持工具与服装身份，让蓝垫从首镜就在台面可见；相邻镜只保留其蓝色重音，背景包装以已有较素的一面朝向机位。理由：重复建立“物归同处”，两次动作提供含义依据。代价：商铺的杂乱气息减少；蓝色本身不等于团结，脱离归还动作就不能这样解释。若包装朝向是必要信息，应保留并另找注意力安排。

**原创同题示范二：一张未领取的票。** 固定条件：15秒静态柜台，黄色票夹仍未取走，人物最后把它交给来客；保留票夹黄色、来客灰外套与原照明。原设计：为“温暖结尾”把末镜所有东西染成橙黄，票夹与柜台混在一起。修改设计：维持原柜台和外套的中性色，让黄色在台面、手中两个位置重复；结尾的变化来自票夹离开柜台，不让它变红或发光。理由：颜色承担身份追踪，行动承担领取。代价：整体暖意较弱，但不应以改变身份换氛围；如需暖意，另比较合法光照或声音方案，不能归因为本次颜色重复已经有效。

**不适用与反例。** “穿红色所以危险”不由颜色自动成立；纪实素材若有不能重拍的多色环境，应优先剪辑与局部可读性，不能要求所有现实物件换色。把同一蓝票夹一镜蓝、一镜紫解释为情绪变化，会破坏身份；确有灯光色偏时需保留物理解释和识别线索。

**练习与判据。** 固定“交还票夹”同一节拍，画三张相邻色块图，标出物件本色、环境照明与唯一允许变化。先不告诉读者颜色规则，请其追踪同一物件并说出发生什么；再看灰度版是否仍有动作/位置依据。记录规则未被读出或没有明显改善，不能只挑认同的解释。

**实际映射与回退。** [visual-bible](../../../templates/visual-bible.json) 的 `palette` 写色板，`intent/composition/lighting` 写它为何重复和光照边界；[asset-bible](../../../templates/asset-bible.json) 的 `identity/variants/references` 固定本色与合法变体。实际画面用固定媒体版本比较，不能把十六进制色值当模型已经准确输出的证据。身份混淆回资产，整镜色偏先查世界光源与后期，含义读不出回动作/节拍；必要时弃用颜色暗示，保留更可靠的轮廓与关系信息。

## 世界光源与跨镜身份 <a id="light-identity"></a>

**适用与输入。** 当正反打都很好看却像两个房间，或夜景关键动作淹没在黑暗中，先固定世界中的光源。输入是地点平面、人物与机位、时间天气、可见及画外灯源、必读脸/手/道具与前后状态。区分光源功能、软硬和阴影边缘，不机械要求每场主光、辅光、轮廓光齐全。本节给照明设计与核查办法，未做实灯、实际渲染或生成测试。

**操作。**

1. 用北/南等固定方向画灯源、遮挡物和机位；写“北窗光”而非每镜都写“画面左侧光”。画面方向会随反打改变，世界光源没有随相机搬家。
2. 写时间、主导色感、阴影边缘软硬、脸与关键物最低可读要求。软硬先看可见阴影过渡，不用“柔美”代替条件；避免伪造实拍色温/光比测量。
3. 同地点建立基准图，再按实际机位画反打面板，标哪一侧朝向灯源、哪里被遮挡。合理的小调整要有同一光源解释，故事中的开关灯另记状态变化。
4. 连看相邻镜的阴影、反光和动作；首帧一致不能证明运动中光源不跳。若灭灯后仍需看清动作，先提出已有环境光或替代覆盖，不凭空添加未经批准光源。

**原创同题示范一：窗边交谈。** 固定条件：夜间工作室，北墙一扇亮窗，甲在桌西、乙在桌东，相机均在桌南侧；20秒，二人位置与窗不改。原设计：甲、乙的近景都要求“画面左侧柔主光”，生成参考却各出现一扇不同位置的窗。修改设计：两镜都继承北窗，顶视图标其从北向桌面照入；逐机位面板说明面部朝窗侧较亮、背窗侧保留可读细节，背景窗是否入画由机位决定。理由：用世界位置解释反打，不靠相同画面标签。代价：某一反打未必最讨好面部；若细节丢失，先调已有反射/机位设计并复核，不把窗换到南墙。实际哪侧投影更亮须看面板和媒体，不能只凭文字判通过。

**原创同题示范二：台灯熄灭。** 固定条件：12秒，桌旁人物关台灯后把杯子放下，窗外已有暗环境光；必须保留关灯和放杯，不新增灯。原设计：每镜独立写“温暖台灯”，关灯后反打仍见同样硬亮斑。修改设计：关灯前记录台灯的小光源感和桌面影边，关灯后继承窗外较弱的环境光，只要求杯子落点轮廓可辨；关灯动作与亮度变化同步，保留声音帮助定位。理由：事件改变了照明状态，不能为脸好看悄悄恢复台灯。代价：关灯后表情信息减少；若表情是必读项，回导演比较关灯前反应或不同机位，不宣称提亮就解释了光源。

**不适用与反例。** 舞台化、不可能光源或有意光向断裂可以是表达选择，但要说明观察任务与变化点，避免被连续性修复抹平。给所有镜头统一滤镜只改色感，不能解决影子相反或新增窗户；“夜景就应看不清”也不能豁免关键动作。

**练习与判据。** 固定一处桌边交接动作，画正反打顶视图及两张面板；标世界灯源、人物朝向、阴影边缘、必须看清的手与物。遮住设计说明请另一读者指出主光来自哪里、两镜是否同地点；若关键信息在缩略图消失就退回。此操作为待执行验法，不能写成已独立复核。

**实际映射与回退。** [visual-bible](../../../templates/visual-bible.json) 的 `lighting` 保存来源与光效意图；[asset-bible](../../../templates/asset-bible.json) 用地点 `identity/variants/references` 保存基准和变化。[continuity-plan](../../../templates/continuity-plan.json) 的 `time_state/lighting_id` 在 `entry_state/exit_state` 继承，`bridge_to_next.match_fields` 只列应延续项，真实关灯处声明变化。`lighting_id` 是引用标签，不是已执行的灯光参数。光向错误回基准/机位，亮度不足先修可读性，模型持续添灯则简化路线或后期/实拍，保留失败媒体再判断。
