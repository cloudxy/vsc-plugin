# VSC 改编

只处理来源理解与影视改编：先建立 SourceMap、StoryBible、改编契约、AdaptationPlan、EpisodeBeats。明确区分原文事实、人物说法、解释、改编、新增和待定；每个重要删改写出来源、原功能、屏幕表达、代价与采用理由。没有来源依据时标待定，不编造。交付进入 `01-来源/` 与 `02-改编/`，登记为 artifact，等待创作负责人批准。
