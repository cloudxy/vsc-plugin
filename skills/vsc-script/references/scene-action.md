# 行动、信息与短片重心

本教材是公开专业方法的原创转译，用于草稿比较与制作交接，不是已验证的作品效果或模型能力。方法背景可读 [John August 的场景写作步骤](https://johnaugust.com/2007/write-scene)与 [BFI 的短片写作建议](https://www.bfi.org.uk/features/writing-tips-from-top)。参考文章不作为台词、人物或镜头的复制许可。以下时长均为练习预算，实际朗读和声画预演后才能记为实测。

**首批参考的实际读取范围（2026-10-24）。** 选择七份一手公开材料，沿既有研究入口复核；只将所列范围用于原创方法，不复制外部剧本、书籍章节、插图或影片。没有取得并通读《故事》《故事解剖》《剧本》《电影艺术》，不写“整书已蒸馏”。

## 让行动分担台词信息 <a id="visual-dialogue"></a>

**适用与输入。** 当人物反复说出观众已经看见的事实，或一句话同时解释动机、动作和结果时，尝试分配信息。输入是固定的表达目标、批准事实、必须保留的措辞、人物关系、地点与时长预算。先区别“能看见的动作”和“只有这个人知道的解释”；纪实数字、回忆的时间跨度、独特叙述视点不能仅靠一个表情替代。本节是设计规格，尚无读者试读、真实表演或生成验证。

**操作。**

1. 给每句划出新增信息，并写清说者希望对象做什么。把“桌上有杯子”与“这是为你留的”分开：前者可见，后者仍需关系语境。
2. 为可外化的信息选择一个有后果的行动：保留、拒绝、遮住、归还或让出。写刺激、动作对象及退出状态，避免只写“显得关心”。
3. 暂时遮住解释句，按动作顺序读一遍；若必要因果消失，恢复一句精确对白或旁白，不把理解困难当高级含蓄。
4. 留出对象接收信息的反应，再朗读台词并计动作、静默。只做本次需要的差异，信息顺序或故事意义变化交回改编决定。

**原创同题示范一：留位。** 固定条件：茶档打烊，店主愿意等迟到的熟客；二人、一处柜台，20秒；保留打烊、等待、对方接受三项事实。原稿：店主翻下营业牌，说“已经打烊了，不过我特意等你，坐这里吧。”熟客说“谢谢你等我。”修改稿：店主翻下牌，手停在最后一只凳上，改把它放回柜台前；熟客到门边问“还来得及？”店主把未收的杯子推到凳前：“热的。”熟客坐下。理由：凳子的去留和杯子的对象分担了邀请与接受，问答保留了营业边界。代价：观众能读到留位，未必能读出二人是熟客；若这层关系必须首次交代，保留称呼或前文依据，不能宣称动作证明全部背景。

**原创同题示范二：保留必要旁白。** 固定条件：观察一位缝补者使用同一只顶针25年；25秒，只拍手、布和顶针；必须保留年数与“继续使用”的视点。原稿旁白：“她拿起顶针，将它戴好。这只顶针用了25年，她继续缝衣。”修改稿：手从浅盒取出磨亮的顶针，顶住针尾穿过厚布；旁白仅留“这只顶针，她用了25年。”针停住，手将松线重新穿好，继续缝。理由：动作承担拿取与使用，旁白承担画面不能证实的年数。代价：磨损只支持使用痕迹，不证明25年；纪实年数须有来源。删到完全无旁白会丢失固定事实，此处保留才服务目标。

**不适用与反例。** “他移开视线，所以他背叛过她”把行为当心理证据；无上下文不能这样推断。实验性独白、口述证言或有意重复可由语言本身构成表达，不必强换成道具动作。抽象概念也不能随便添一个象征物来假装完成叙事。

**练习与判据。** 写一段18秒“把最后一把干椅留给来客”，只准二人、一把椅、原地点。A稿让语言承担邀请，B稿让行动承担邀请；两稿同样认真完成。给未看说明的读者只读正文，请其指出谁邀请谁、凭哪一处判断、还不知道什么；另计朗读和动作时间。这是待执行的比较，不是教材已有成绩。

**实际映射与回退。** 依 [screenplay 模板](../../../templates/screenplay.json)，正文放 `body`，动作放 `scenes[].actions[]` 的 `id/text/narrative_refs`，台词放 `dialogue[]` 的稳定行ID、`text/speaker/narrative_refs`；静默用 `silence[]` 的 `id/duration_ms/purpose/narrative_refs`，场时长用 `estimated_duration_ms`，不得把预算写成媒体实测。导演通过 [coverage 模板](../../../templates/coverage-plan.json) 的 `screenplay_unit_ids` 保留动作与反应覆盖。读者关系认错先补关系语境，因果丢失恢复必要语言，超时先减重复信息；不能靠加速配音掩盖动作无容纳空间。

### 行动必须产生可追的后果

**原创深写：只剩一张纸。** 两人、一张借用的工作桌、一张最后的裁纸；30秒内。固定事实：学徒第一次独立裁纸，师傅赶着收桌，学徒要求最后一次核对，师傅同意留桌；不能改成师傅代裁或材料无限。不要求把“师徒”读成亲属。

初稿正文：师傅把桌角折起。学徒按住纸：“等一下，我还没核准。”师傅：“赶时间，快点。”学徒：“这是最后一张，我怕裁坏。你再帮我看看。”师傅看一下纸：“没问题。”学徒开始裁。

局部修订正文：师傅折起桌角。纸向下滑，学徒双手压住：“等一下。”师傅扶住桌角：“还没裁？”学徒将尺放回折痕：“最后一张。让我再量一次。”师傅停住，放平桌角，退到尺外。学徒把两边刻线对齐，抬头；师傅没有接尺。学徒自己落刀。

| 原处 | 真正改变的内容 | 保留与代价 |
| --- | --- | --- |
| “我怕裁坏” | 纸被按住、尺重新对线，把担心落成争取核对的行动 | “最后一张”仍直说，纸本身不能证明库存。 |
| 师傅看后保证“没问题” | 师傅让桌、留时间但不接尺，学徒仍承担自己的决定 | 保留允许核对，删去“师傅担保正确”；若此担保是批准事实，此修法不适用，须恢复或退改编。 |
| “学徒开始裁” | 接收留桌后才落刀 | 需要看得清桌角/尺/手；导演可简化接触，不能靠解释“他独立了”弥补缺镜。 |

这段的推进是“要求停下→对方让出时间/空间→自己做”，不是“台词删得多”。有意不用行动替换的有效版本可保留原稿三句核对：若目标是示范裁纸安全口令，就让师傅明确重复尺寸，学徒复述后再裁；信息清楚优先，不以含蓄判它失败。

**失败与返回点。** 只添颤手、汗珠却仍由师傅代裁，会改变固定选择；在最后才补“原来那是遗物”则偷加代价。前者回最后行动，后者回来源/改编。新练习改为“二人、一枚已贴错位置但可揭下的标签，20秒，保留请求核对与本人改正”，分别写语言核对版和行动分担版。遮住目标说明，请新读者指出谁争取了什么、谁改变了什么、结尾谁承担行动；未有实际读者时只记录待验证，不给本教材自判通过。

## 短片集中一个核心变化 <a id="short-film-focus"></a>

**适用与输入。** 当有限时长内有许多事件，却说不清观众在结束时比开头多理解了什么，使用本法。输入是批准的主题、事实与删改边界、段落顺序、核心人物或观察视点、片长预算。剧情可比较人物的选择；散文可比较观察的变化；纪实可比较主张获得了什么证据。不强制所有形式出现人物弧光或冲突。本节提供原创设计示范，未完成受众测试或真实媒体试证。

**操作。**

1. 写一句可观察的起止差异，避免“从痛苦到成长”这类无法定位的概括。例如“先把工具收回，后来把最后一步交给对方”。
2. 逐段标它带来的新证据、选择或意象联系，以及删去会损失什么。相同信息第二次出现时，说明它为什么值得占用时长。
3. 固定必须保留项，将可选背景改成短线索或提出删改建议；批准事实不能为追求集中而静默改写。改变故事意义交回改编。
4. 给关键变化留行动和接收时间，再试读整段。比较删改后是否更易读，也检查是否损失生活感、歧义或声音节奏。

**原创同题示范一：让出最后一步。** 固定条件：修伞摊，师傅由亲自检查改为信任学徒；二人、一把修好的伞，30秒；伞骨已修好、师傅最后让学徒试水是必留项，旧顾客与租金是批准的可选背景。原稿：师傅谈租金，学徒提旧顾客，然后说修好了；师傅接伞、试水，再说“以后交给你”。修改稿：学徒递伞；师傅接住伞柄，摸到补好的伞骨，伸手向水盆；学徒仍扶着伞。他停一下，把柄转回学徒手中：“你试。”学徒撑开伞。理由：选择集中在谁完成检查，结尾信任有可见动作。代价：租金与旧顾客的地方气息减少；若它们是必要因果，先申请更宽片长或改段落范围，不能擅删。是否更清楚仍需同预算试读。

**原创同题示范二：观察也有重心。** 固定条件：30秒观察清晨屋檐滴水，目标为“同一滴水从杂音变成可辨的节奏”；无人物，保留檐口、铁盆、渐稀滴声，不新增天气因果。原稿：依次写天空、树、巷道、盆、檐口，各配一句感叹。修改稿：从檐口下的密集滴声开始，画面容纳铁盆边缘；滴声变稀，盆中波纹一次次分开，最后一滴后停留空盆声场。理由：观察位置和声音间隔形成联系，未为无人物段落强造选择。代价：视野变窄、信息较少；若作品追求城市漫游，多点并置可能更合适，不能按剧情集中法判它不合格。

**不适用与反例。** 多声部合唱或并列证言本来就要保留不同视点；将它们压成一人“顿悟”可能扭曲事实。原稿已有清晰单一变化时，强加反转会让结尾失真。“删掉全部前因，只留一次哭泣”虽然短，却无法说明变化来自哪里，不是集中表达。

**练习与判据。** 固定25秒、同一窗台和一盆植物，分别写“发现新叶”和“观察光影经过”两种目标；先选一个，再做同目标的前后两稿。逐段标新增信息与代价，遮住意图说明请读者复述开始、结束及连接依据。判据是目标下的联系能被指出、必要事实保留、时长可容纳；不是主题数越少得分越高。没有改善也保留这个结论。

**实际映射与回退。** 在 [screenplay 模板](../../../templates/screenplay.json) 的 `body` 保留可读正文，分段映射到 `scenes[].actions/dialogue/silence` 的稳定ID与 `narrative_refs`，`adaptation_refs` 固定批准依据，`estimated_duration_ms` 仅为预计值。核心变化是写作判断，模板没有同名机器评分字段，不新增虚构参数。下游以 [coverage](../../../templates/coverage-plan.json) 的 `screenplay_unit_ids` 找回每段，批准的省略走原 `omissions`。若集中后因果断裂，恢复前因；超时回调内容密度；多声部确有必要则换组织方法，不硬改作品形式。

### 根据意见局部重写 <a id="rewrite-local"></a>

本节继续使用 `short-film-focus`，不新增同义卡。依据 [BFI](https://www.bfi.org.uk/features/writing-tips-from-top) 的修订与新读者反馈、[John August](https://johnaugust.com/2007/write-scene) 的场景作用检验，先定位正文中哪一处没有传达目标，再选改动层级。人物选择、关系或信息顺序需要改变时回改编；只有一句重复时不重写全场。意见里的解决办法也可比较，不能将“读不清”直接改写成“用户要求加旁白”。

**原创初稿。** 社区排练室，二人、一个装道具的纸箱，25秒。固定事实：甲要离开，乙需要对方帮忙抬箱到门口，甲答应这一次；保留最后一句“就到门口”，不新增和解。正文：甲提包。乙：“你准备走了？我一个人搬不动这个箱子。你以前也总是这样，一到最后就走。”甲：“我不是不想帮忙，我已经答应别人了，不过搬这一次也可以。就到门口。”甲放下包，二人抬箱。

**本轮意见与保留项。** “解释太满，改短；保留乙争取帮忙和甲只答应一次，别写成重归于好。”问题在两处重复解释，不是冲突、结局或身份不对。针对性修订：甲提包。乙将箱子一角抬起，另一角拖地：“搭把手？”甲看向门口，把包挎上肩，握住另一侧：“就到门口。”二人抬箱。

| 定位 | 局部差异及原因 |
| --- | --- |
| 乙的整行 | 删掉已可见的离开/搬不动说明和未经本轮要求保留的“总是”；以请求和抬起失败表达当前需求。若“以往总离开”是必须保留事实，另留一句精确指责，此示例不能授权删掉。 |
| 甲的整行 | 删自我辩解，原样保留“就到门口”；包仍在肩上，接受有限帮助没有变成留下。 |
| 收尾行动 | 保留二人抬箱，不添拥抱、放下包或久留的动作；这些会扩大为和解。 |

**有效的不采用版本。** 若用户的真正目标是“乙故意翻旧账逼甲答应”，原稿指责可保留，只缩甲的回答：“我还得赶过去。就到门口。”关系刺痛是表达目的，不能按短句偏好抹平。反例是把甲改成“我不走了”，虽顺畅却改了固定结果；回甲的回应和包的退出状态，不用新解说遮掩。

**练习与退出。** 新题：二人在楼梯口，一只空水桶，20秒；甲只答应送到下一层，固定“下一层”为边界。意见仅为“不要重复解释桶轻，保留关系里的不情愿”。先独立完成认真基线，再只修相关行，列保留项与实际差异；新读者先复述结果/边界，再指出哪里读出不情愿，允许相等或无法判断。没有真人判断不写效果通过。若读者把有限帮助读成和解，回限定词与退出动作；若只是更短而因果丢失，恢复必要语言。

应用回原工作副本稳定场/行：一次意见可有多处差异，但只通过现有建议链交付可接受/撤销的改动。提交版本与当前草稿冲突先恢复基线，接受建议不自动批准；构思时不要求先填机器字段，正式交接再映射 `body` 与结构行。导演以改后实际稿检查动作和反应是否可覆盖，不能仅凭这份改稿说明安排镜头。

## 信息先后与可见线索 <a id="reveal-detail"></a>

沿原 `reveal-detail` 卡，不另建“反转”卡。依据 [Yale Editing](https://filmanalysis.yale.edu/editing/) 的细节切入、视线和连续性文字说明，将“谁知道什么”落实到实际可看/可听顺序；场景作用参考 [John August](https://johnaugust.com/2007/write-scene)。以下公平揭示的步骤是 VSC 的原创应用办法，不把它冒称为来源逐字规则或普遍唯一结构。

**适用与做法。** 适用于要让观众更新判断的场景。固定事实与视点，写观众、甲、乙开始分别知道什么；为必要推断安排可观察依据，按“线索出现→有人接收→行为改变→后果”试读。可选择观众先知、与人物同知或暂不知，但不能在人物已经知道时用不合理反应强装惊讶。线索不必特写，声音或同景中可读的细节也可承担；导演检查看得见/听得见、停留可容纳。纪实只据真实来源，不为戏剧性调换事实因果。

**原创初稿：同一把钥匙。** 二人、一张归还台、一个已打开的钥匙盒，35秒。固定事实：甲来还钥匙以为最后离开；乙已给甲留周末值班位置；乙没有另配新钥匙。盒中有写着“周六：甲”的排班卡，甲到结尾才发现安排；必须保留甲自己把同一把钥匙取回。

初稿正文：甲把钥匙放进盒里：“都还了。”乙点头。甲转身；乙：“其实我留了你周六的班。”甲吃惊：“你还让我来？”乙：“卡就在盒里。”甲回到台前，取回钥匙。

针对性修订：甲把钥匙放进盒里，钥匙压住卡角：“都还了。”乙把盒转向甲，指尖停在露出的“周六”边上。甲已转身，听见盒底擦台的声音，回头。乙松手。甲走回，抬起钥匙，读到“周六：甲”，停一下，将钥匙握回手里：“几点？”

| 先后 | 观众/人物获得的依据与局部变化 |
| --- | --- |
| 初稿末句才补排班卡 | 观众无法在正文前部追到安排；改稿在放钥匙时先出现卡，再让盒的移动有声音和接收者。 |
| “周六”先露、“甲”后读到 | 暂时保留卡的对象问题；甲取钥匙后自己确认名字。名字若既不可读也无声音补充，不能只在说明里写“观众明白”。 |
| 取回同一把钥匙并问时间 | 以行为兑现安排；不必再解释“我接受邀请了”，也不推断二人的亲密关系。 |

**有意不制造悬念的有效版本。** 若表达目标是观察两人协商，开场就让甲读卡：“周六也要我来？”乙：“你方便吗？”甲将钥匙放下又拿起：“上午。”信息直接，却保留选择和对象；不按“揭示晚”奖励它。若字幕/画面无法可靠呈现小字，采用清楚问答也可能更好。

**失败与返回点。** 为反转在最后突然说钥匙属于第三个人，改变固定事实；或开场已清楚看见完整卡，随后还要求观众当作全新消息。前者回来源/改编，后者回线索可见度与反应。表演或剪辑没让甲接收到转盒声音，则先补接收/空间依据，不在字幕补一段心理。练习：二人、一张窗边桌、两只装不同标记杯子的托盘，25秒；一人原以为送错桌，看到可见标记后自己改送。写观众先知与同知两版，固定同一事实与后果；请新读者按顺序复述依据、误解与更新位置，找不到则返回最早缺线索处。

**映射与交接。** 保留正文和稳定 `actions/dialogue/silence` ID，`narrative_refs` 指回已准事实。导演用 `coverage-plan` 的 `screenplay_unit_ids` 记录线索和接收的覆盖；跨场未决信息沿原 `sequence-links`，不另存第二套“揭示已完成”。时长只是预算，细字、静默和反应实际可读须由朗读/预演或媒体检验。能指出文字线索不等于真人已理解或成片已经公平。
