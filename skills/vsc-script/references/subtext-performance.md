# 潜台词、行动与倾听

本教材把关系与可执行行动用于原创草稿比较；专业背景可读 [Judith Weston 的导演建议](https://judithweston.com/web/archive/top-10-ideas-directing-actors)。它支持用对象、行动和倾听工作，不保证生成模型能稳定执行停顿或细微动作，也不支持用眼神测谎。所有范例为教学新写，时长为预算，未进行表演试拍或受众评测。

## 对白的表层话题与暗中目标 <a id="dialogue-subtext"></a>

**适用与输入。** 当台词把关系直接命名、角色只轮流解释或不同人物说话一样时，先检查说话目的。输入包括固定台词事实、说话对象、前一刺激、不能直说的原因、人物语言习惯、时长与必须保留的句子。潜台词是本场语境支持的行动意图，不是作者在括号里宣布的秘密；纪实证言与清楚告知不必刻意含糊。本节为可操作的设计规格，尚未证明模型或演员按此执行的效果。

**操作。**

1. 为一轮话写“希望对方做什么”，如留下、承认、允许或结束。一个含糊情绪词不能代替对象与目的。
2. 固定表面话题，选择一种言语行动：试探、邀请、搪塞、说服。用措辞、回应顺序或停顿中的一项承载，不把所有细节同时改变。
3. 设计对方真正听到后的反应。下一句必须回应收到的信息，不能只是等待自己的台词。
4. 朗读两稿，区分角色身份、关系与本句演绎。听不懂时先补语境或改措辞；必要信息可以直说，字幕不负责解释失败的潜台词。

**原创同题示范一：是否留下。** 固定条件：二人在社区厨房收拾，甲希望乙再留一会儿，乙尚未答应；只用“汤还热着”“我把碗洗完”等厨房事实，20秒。原稿：甲“我不想你这么早走。”乙“我也想陪你，但不知道你愿不愿意。”修改稿：乙放下擦干的碗，拿起外套。甲：“汤还热着。”乙的手留在袖口：“你还没吃？”甲把自己面前的空碗移开一点：“一个人，懒得盛。”乙把外套搭回椅背：“我把这只碗洗完。”理由：甲以汤邀请，乙以继续劳动接受少量停留；回应改变了离开的行动。代价：互相陪伴的愿望没有被明说，若前文缺关系基础，可能只读成普通加班，应补语境或恢复一句明确邀请。此稿没有证明爱情等更具体关系。

**原创同题示范二：同句找到对象。** 固定条件：邻居在门口归还折椅，甲希望有机会再见乙，乙同意让椅子继续留在甲处；台词必须为“明天还用吗？”“先放你那儿吧。”，15秒，身份与折椅状态不改。原稿只有甲“紧张地”询问、乙“温柔地”回答；甲带椅离开，缺少接收的过程。修改稿：甲递出椅子后仍扶着椅背，问“明天还用吗？”乙先看甲，再把椅子轻推回：“先放你那儿吧。”甲接稳椅子，等乙松手才转身。理由：固定台词中，甲用确认借用试探下一次联系，乙通过接收后推回容许关系继续；行为有对象而非只有声调标签。代价：可能仍被读成普通邻里借物，不能宣称它证明爱意；若“再见”的意图必须毫无歧义，补已批准的关系语境，或提出更明确对白的修订，不靠解释备注代替正文。

**不适用与反例。** 把“请在火警响后走楼梯”改成隐晦玩笑，会损害告知用途。所有角色都绕开问题、句句省略，观众会失去事实锚点；这不等于丰富潜台词。把口音、阶层或某种手势当作“天生虚伪”的模板也没有语境依据。

**练习与判据。** 固定一句“伞放这里就行”，写“希望对方再来”与“礼貌结束”各一版，二人、门口、15秒，身份、道具及句子相同。每版只选一个主要言语行动，给倾听者一次回应。先让读者复述谁希望谁做什么，再指出依据；最后透露目标，记录歧义。目标是找到可感依据与可修改位置，不是让人猜中一个情绪词。

**实际映射与回退。** 在 [screenplay](../../../templates/screenplay.json) 的 `body` 写表演语境，`scenes[].dialogue[]` 固定 `id/text/speaker/narrative_refs`，动作与反应分别给 `actions[]` ID，停顿用 `silence[]` 而不塞进待朗读台词。声音交接使用已有 dialogue Cue 的 `line_id/text/speaker/acting_choice/lip_sync_intent`，身份与台词不得因换演绎而漂移。模板没有“潜台词分值”。目的读错先修刺激与回应，语言超时回写作，声音平淡回表演/选take；涉及故事意义则回改编，不增加更长情绪标签蒙混。

## 动作与潜台词共同作用 <a id="gesture-subtext"></a>

**适用与输入。** 当剧本只有“悲伤地”“克制地”，或人物说话时对方像静态背景时，把情绪要求改为对对象的尝试。输入是固定场景事实、刚发生的刺激、行动目的、身体与持物进入状态、最终景别、时长预算。先问“这个动作想对谁做什么”，再选看、递、收、停或让路。不以回避视线推断说谎，不把一次动作当心理诊断。本节为原创设计规格，未进行演员/模型实测。

**操作。**

1. 按刺激→接收→选择→行动列一个关键拍。例如“听见对方要走”发生在“收回椅子”之前，不能让反应抢在诱因前。
2. 选择一项可见身体行动并注明对象与终点，如“将对方的杯子留在桌上”；避免同时命令皱眉、颤唇、握拳、眨眼和叹息。
3. 给倾听者一段可以读出的时间，并检查景别是否看得到所选线索。远景中看不见的指尖细节应换更合适的身体行动或覆盖。
4. 固定台词与声音身份比较动作版本；先正常速度观看完整区间，再定位瞬间。身体、持物和呼吸须继承上镜状态，动作减小不等于完全僵住。

**原创同题示范一：愿意帮忙但不承认。** 固定条件：二人在工作台旁，甲把未完成的纸盒推给乙，乙愿意继续帮忙，必须保留“我只做这一个”；20秒、一只纸盒与胶带。原稿：乙“我只做这一个”，括号写“嘴硬心软，感动又无奈”。修改稿：甲推盒时胶带松开。乙先按住盒角，再抬眼看甲：“我只做这一个。”甲伸手要接，乙把胶带拉到自己一侧继续封口；甲停手，留在桌边。理由：帮忙由抢先按住和继续封口体现，台词维持口头界限，对方有接收与回应。代价：细手部动作增加接触连续性难度；生成路线若做不清，保留按住盒角的单一动作，或改成台面双人中景，不靠叠加表情补足。

**原创同题示范二：倾听改变下一步。** 固定条件：20秒，二人在候车椅旁，甲听见乙说“我改坐下一班”；甲本来准备离开，随后坐回，保留这句和选择变化。原稿：乙说台词；甲“很高兴地坐下，露出自然微笑”。修改稿：甲刚把包带提到肩上；听见“下一班”后，看向乙腾出的半个座位，放下包，坐回原处：“那我再等一会儿。”乙把自己的包挪开。理由：线索来自听见、寻找可坐位置与让位，表演有对象和后果。代价：不强调笑容，喜悦可能被读成安心或犹豫；若必须区分，应比较一句回应或身体节奏，不宣称某个眼神具有固定情绪含义。

**不适用与反例。** “说谎者摸鼻子，诚实者直视”是无依据的身体字典。庄重仪式、静止肖像或故意麻木的段落可以很少动作，但仍要说明观察任务；不能为了填表给每句添手势。前后镜把杯子从右手变到左手，再用“内心混乱”解释，属于连续性错误。

**练习与判据。** 固定“先放桌上吧”、一只盒子、二人和15秒，写“接受帮助但维持距离”的前后两稿。第一稿认真采用自己的做法，第二稿只改变一次接收后的身体选择。画出三格刺激、反应、退出状态，请读者指出帮助有没有被接受、凭什么知道。另检查手、盒子、站位能否连续；若只有情绪标签变化，练习尚未落到行动。

**实际映射与回退。** [screenplay](../../../templates/screenplay.json) 的 `actions[].text` 写可观察行为，`dialogue[]` 固定行ID与原句，`silence[]` 容纳有目的反应；预计时间写 `estimated_duration_ms`。[continuity-plan](../../../templates/continuity-plan.json) 通过 `entry_state/exit_state.characters` 的 `pose/prop` 和 `handles` 保存边界。`acting_choice` 进入已有声音Cue只说明本句演绎，不代表所有动作都有供应商控制。意图不清回刺激/对象，动作读不到回景别/调度，接触持续失败时简化或换实拍/合成路线；文字设计不能记为真实表演通过。
