# 维护执行模式（媒体与迁移类任务）

从实际维护会话提炼的通用执行模式，供 [vsc-architecture](../SKILL.md) 实施模式与 [vsc-engineer](../../vsc-engineer/SKILL.md) 按职责读取。模式正文只在此维护；具体案例、路径与版本留在本机维护台账，不复制进公开规则。

## 预算与配额类任务

- **满额即报**：消耗型预算（存储、配额、调用次数）把"已用/上限/剩余"作为进度汇报固定字段，贴满时精确报数（如剩余 3.1MiB），让提额或砍量决策零成本；不默默贴顶停止。
- **三档递进**：预算、目标量、完成度分开陈述；"预算内完成多少 / 达成全部目标还需多少"两句话讲清。

## 长下载与批量媒体任务

- **断点续传 + 分段校验**：大媒体任务保留逐文件/逐段进度记录，恢复时从断点继续并逐段做哈希校验；进度播报含"分段失败 N"计数，N>0 逐条列明。
- **大文件并行分段**：单个 GB 级文件改分段并行下载，失败段单独重试，不整文件重来。
- **恢复即接续**：中断后凭"计划文档 + 状态 JSON + 校验记录"三件恢复，接续动作先复述断点位置再执行，用户只需说继续。

## 迁移与存储治理

- **迁移五步链**（两次实证零返工）：改读取路径并过测试 → 移实物（同卷 rename 优先，不复制）→ 前后逐文件哈希/摘要比对 → 重启服务实机验收 → 提交推送。次序不可倒置，先移实物必炸引用。
- **配置唯一权威**：先盘点同名配置的全部覆盖源（默认值、项目 env、shell 导出、进程环境），一次迁移同步所有源并验证"无环境变量时走默认值"路径；shell 全局导出不放项目配置。
- **清理双确认**：删重复资源前先按内容哈希确认保留副本完整、再确认无引用，两证齐全才删；静默降级（过滤缺失项）改为显式标记缺失，不隐藏。

## 验证与交付

- **验收三件套防"存在即完成"**：以"结构集合一致（ID/数量对齐原对象）+ 内容本地可用（可播/可读）+ 入口可达（从真实页面走到）"三件验收；文件落盘、快照存在、接口 200 都不等于任务完成。
- **修前修后对仗留证**：修 bug 先跑出失败基线（N 项失败），修复后同集全过，两个数字写入提交说明；对照记录可直接进审计材料。
- **版本载体单 patch**：功能改动、测试、全部版本号载体文件一次原子更新，杜绝发版漂移；纯发版可独立成 patch。
- **隐藏配置源优先排查**：环境变量覆盖配置文件的"看起来改了没生效"问题，先 `env`/进程环境再查代码；已启动进程继承旧值，改完必须重启并用纯净环境验证。

## 会话协作

- **并行工作区纪律**：同仓库多会话并行时，各自只提交自己的路径；推送前工作区必须干净，他人未提交改动存在时不 stash 不代交，等其落盘或升级给用户决定。
- **一次授权降往返**：用户明确"按推荐直接执行"后，后续同类决策不再逐项确认，但在交付汇报中列出全部自主决定清单供追溯。
