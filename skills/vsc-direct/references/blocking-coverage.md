# 调度、空间方向与必要覆盖

本教材用于把固定剧本变成可以检查的空间和剪辑条件。专业背景可读 [Yale 的场面设计](https://filmanalysis.yale.edu/mise-en-scene/)与 [剪辑分析](https://filmanalysis.yale.edu/editing/)。以下原创例子与平面关系都是设计规格；静帧兼容不能证明生成片段中的接触、视线或移动成功。本教材没有完成独立导演/连续性验收，也不把守轴线等同审美合格。

## 同题交接：从空泛描述到可执行镜头 <a id="usable-shot"></a>

**固定题目。** 原创合成场段“归还钥匙”：12秒，甲在维修台西侧、乙在东侧，相机在南；甲把带缺口的铜钥匙放在台中央，收回右手，乙停一下后用左手取走。无对白，人物、地点、动作顺序与钥匙身份不改。任务是给资产和生成两方同一份镜头设计，不是制作视频。

**对此用途无效的交付。** “电影感近景，紧张氛围，流畅运镜，钥匙象征和解；分镜已完成。”接收者不知道在哪拍、谁持物、动作如何开始或结束，也不能从“和解”推导未经给定的心理事实。

**可交接的设计示例。** 固定南侧机位、台面及双手可见：第一镜4秒，入点为甲右手持钥匙，落台并收手，出点钥匙静置中央、乙左手尚未进入；第二镜5秒，保持南侧和同一钥匙朝向，入点静置，乙停顿后左手伸入取走，出点钥匙在乙手中；第三镜3秒，延续乙持物离台的结果，保留台中央空位。将覆盖关系、必要参考和真实待定的剪辑余量写回原 shot_plan/coverage，不凭这组文字宣称已取得可剪手柄。第二镜不必为了术语齐全增加拉焦或绕拍。

**接收者怎样继续。** asset-director 从同一设计列出南侧台面和铜钥匙缺口/落台状态所需视图；generation-producer 据第二镜的入出状态核参考输入及供应商路线，记录尚缺的固定媒体。两方引用同一版本，不再各写一份同义分镜。若只有第一镜末态的静帧，不能据此宣称5秒取钥匙动作成功。

**检查与回退。** 让接收者只读这份设计，指出每镜持物者、动作先后、可见接点与所需参考；缺项回该镜设计，缺实际参考回资产。若12秒无法读出停顿，先比较局部时长分配并回看预演；不能改动作、加台词或直接无限重抽。以上是文字交接练习，实际媒体及专业效果另验；更详细不自动更好，足以供当前用途接续即可。

## 让位置变化承担关系变化 <a id="space-blocking"></a>

**适用与输入。** 当台词说关系变化，画面却只是两个人站着，或交接动作无法跨镜接上时，先做调度。输入是固定剧本单元、地点几何、人物与道具身份、起止状态、必要观众信息和时长预算。位置可以表达接近、退让、阻隔或共同面对某物；距离本身没有固定心理含义。观察性、仪式性段落可保持静止，不必强加冲突。本节是设计方法，尚未用真实媒体验证运动。

**操作。**

1. 画顶视图，标北向、门窗、人物、主要道具与声源。世界位置与画面左右分别记录，同地点反打复用同一几何。
2. 按刺激、选择、行动、退出状态标人物起止与路线；持物写谁、哪只手、什么姿态，交接写两人何时同时接触和何时放手。
3. 先选最小覆盖：建立关系、关键行动、必要反应。每镜说明承接哪一剧本单元、增加什么信息、入点与出点；插入镜只补确实缺失的信息。
4. 用面板接一次动作，检查遮挡与出入点，再决定景别和运镜。运动已复杂时先用稳定机位，不同时增加绕行和精细交接。

**原创同题示范一：递盒。** 固定条件：15秒，两人隔工作台交接纸盒；甲在西、乙在东，相机在南；观众须看出乙从犹豫到接下，不改台词或身份。原设计：先给甲脸部特写，再给乙脸部特写，第三镜盒子已在乙怀中。修改设计：先用南侧双人中景建立台面与两手；甲用右手把盒子推到中央，乙左手先碰盒角而未收，保留反应，再双手接稳，甲松手；必要近景只覆盖接触到放手的区间。理由：位置和持物变化提供接受的证据。代价：动作比直接切结果占时，双手接触对生成更难；失败时先改单一台面推送或实拍插入，不在未同意时把“接下”改为口头答应。设计可剪不代表媒体可剪。

**原创同题示范二：让路。** 固定条件：18秒，窄门口二人，甲从挡住出口改为允许乙离开；门朝北、二人均不出新地点，保留关系变化。原设计：甲说“你走吧”，一直站在门正中，乙下一镜已在外面。修改设计：先建立甲与门框之间不足以通过的空隙；听到乙的请求后，甲移到门西侧，手收离门框，乙经过，甲留在门内。理由：让出的路线使语言产生可见后果，出入点连贯。代价：窄门动作可能遮脸，需在面板检查可见侧；若身体通过持续变形，比较更宽的批准机位或在门内完成放行，不能凭空拓宽既定地点。

**不适用与反例。** 让两人越走越近，却说“关系必然亲密”，忽略了威胁、拥挤等语境。为展示调度绕桌走一圈，会增加运动而未必增加信息。无行动任务的静态观察可以保持位置；调度不是要求人物每句移动。

**练习与判据。** 同一“递盒”动作画顶视图和三格面板，标甲右手持有→双方接触→乙双手接稳，机位与盒子身份固定。让另一读者只按图接通一次，指出每格谁持物、从哪边进入、在哪里放手；若出现重叠递送、瞬移或缺接收反应即退回。这个练习为待执行验法，不是现成独立复核证据。

**实际映射与回退。** 原 `shot_plan` 使用 [continuity-plan](../../../templates/continuity-plan.json) 的 `shots[].id/duration_ms/reference_asset_ids`，在 `entry_state/exit_state.characters` 写 `pose/prop`，相机用 `camera.framing/motion/screen_direction`，`handles` 留可剪余量；顶视图是镜头设计附件，不虚构通用坐标接口。[coverage](../../../templates/coverage-plan.json) 的 `shots[].screenplay_unit_ids` 绑定实际行动与反应。缺因果回剧本，遮挡回布局，交接断裂回状态/切点，复杂动作不可执行时换分镜或制作路线，不用字幕替物理动作补解释。

**动作过程按需检查。** 从当前动作的风险选用下表，不要求每个动作套同一组阶段。先写身体在世界中的路线、支撑与持物，再写机位能看见什么，最后安排切点；不把画面左右当世界路线。复用现有实体、入出状态和coverage，不为检查补造角色、坐标或机器相位。

| 动作组 | 身体／道具过程要核什么 | 机位与剪辑怎样接续 |
| --- | --- | --- |
| 跑跳 | 起止方向、加减速、脚下支撑、腾空与落地后的重心能否接通 | 保留起跳或落脚的必要可见区；切后不能凭空换支撑脚、速度或世界方向 |
| 跌倒 | 失衡方向、身体与地面/物体的接触、冲击反馈及随后撑起或恢复的状态 | 让必要触点与结果可读；切到起身时承接已倒姿态，不靠跳切掩盖穿地或无接触 |
| 潜行 | 身体路线与遮挡；题目已有观察者时核其视线，别为凑攻防加人 | 相机遮住人物不等于人物躲过观察；必要时建立双方与遮挡物的位置，再决定切换 |
| 攻防 | 脚下支撑、腰肩与手臂发力是否连贯，攻击路线与防守/闪避的相对位置；不固定一种发力顺序 | 合法未中须保留擦过/避开的空间和后续平衡，不强造接触或受击反馈；切后不得重复起手 |
| 剑术 | 谁用哪只手持剑/持鞘，剑尖、剑身、鞘口相对身体的方向，拔收或换手前后持物是否一致 | 选能读清手、剑、鞘关系的角度；遮挡处切换仍须承接方向，不以镜头翻转修正持物错误 |
| 施法 | 身体动作与能量起点、出现/行进及反馈的先后和同步，效果是否跟随既定身体部位；仅使用已有施受对象 | 交代身体与效果的前后遮挡、注意目标和结束状态；光效不能盖掉关键动作，切后保留已定结果 |

表中条件写回原镜头描述和状态/覆盖；面板只能检查姿态与可见关系。实际速度、支撑、接触、身体与能量同步须连播媒体再判断，静态示意不证明动态成功。缺接点先回设计，参考/输入正确而执行未兑现回制作；有可用区间时由编辑按实际源区间继续。

## 轴线、机位侧与可读过渡 <a id="axis-map"></a>

**适用与输入。** 当切后人物像互换位置、运动突然反向，或多次反打找不到门时，检查轴线。输入是固定场段、顶视图、人物关系线或运动路线、各镜机位、起止方向及必要覆盖。轴线是帮助观众建立方向的工具，不是审美评分，也不是永远不许跨越的世界边界；人物关系与行动改变时，主导线也可能改变。本节为设计规格，首尾面板不证明中途相机没有越线。

**操作。**

1. 在世界平面画当前关系线，说明哪一段由这条线组织。两人对话以二人关系为主，走廊行进可能以运动路线为主，不能只写一个“守轴”标签。
2. 标每镜机位所在侧和面向；从机位投影检查画面左右、视线与出入方向。反打是改变看谁，未必改变机位侧。
3. 要换侧时，选择可读的连续移动、明确重建关系的全景或人物关系重组；逐段核对新轴从哪一刻开始成立。正对轴线的镜头不能自动修复后续所有矛盾。
4. 按正常观看顺序连面板，先问能否定位，再看是否服务表达。有意迷失方向可以保留，但须有目标和恢复点。

**原创同题示范一：桌边问答。** 固定条件：20秒，甲在西(-1,0)、乙在东(1,0)，北为+y；机位初在南(0,-3)，甲画面左、乙画面右，问答与站位不改。原设计：甲近景机位在南，乙近景机位跳到北，二人在相邻画面都朝同一侧，门的位置也反转。修改设计：甲、乙近景机位都在关系线南侧，分别从东南看甲、西南看乙；面板核对甲朝画面右、乙朝画面左，门保留同一世界位置。理由：同侧覆盖保留已建立的左右关系。代价：可用背景和角度受限；如需要北侧窗背景，先设计换侧过渡，不把背景偏好偷偷替代空间条件。

**原创同题示范二：有理由换侧。** 固定条件：15秒，人物沿东西走廊向东搬椅，目标是让观众跟随其经过门口；同一路线与结局。原设计：南侧镜人物由左向右走，直接切北侧镜仍写“继续向右”，实际等于把世界方向写反。修改设计：先保持南侧走向；在门口用一段可读的连续相机移动或重建全景交代到北侧，随后人物在画面由右向左继续向东。理由：世界行进没变，屏幕方向随观察侧改变，过渡提供定位依据。代价：连续换侧的生成难度高；若不支持，选择有清楚门与行进关系的重建镜，或全段留南侧。不要承诺提示词“绕到背面”一定产生可用轨迹。

**不适用与反例。** “双方都朝右所以越轴”还需结合目标和关系线，单帧不能定罪；人物可能都在看同一画外物。故意跳轴的紧张表达未必错误，但若观众已无法判断谁追谁且目标要求清楚，不能用“艺术选择”回避失败。全段守同侧也可能缺空间信息。

**练习与判据。** 固定一个“甲递盒给乙”的顶视图，画两组反打：一组保持南侧，一组经可见过渡到北侧。每格写机位侧、对象、画面方向和持物状态。让读者指出甲乙、盒子与门的相对位置；判断依据为信息能否接通，镜头数和规则遵守率不是成绩。

**实际映射与回退。** 用 [continuity-plan](../../../templates/continuity-plan.json) 的 `entry_state/exit_state.camera.screen_direction` 记录投影方向，`framing/motion` 说明观察方式，角色 `pose/prop` 保存关系状态；`bridge_to_next.strategy/purpose/match_fields` 只约束确实应延续的项，换侧处明确理由。顶视图是既有镜头设计附件，模板没有独立 `axis_side` 强制字段；不要伪造新参数。[coverage](../../../templates/coverage-plan.json) 固定镜头与剧本单元。方向不清先修机位侧/过渡，中间运动失败回实际take检查，必要时取消换侧，不因首尾正确就判整段连续。

## 视线、目标与接收反应 <a id="eyeline-match"></a>

**适用与输入。** 当人物看向一边，下镜对象却像在另一处，或反应发生在看见之前时，分别设计“看哪里、看见什么、随后做什么”。输入是人物位置与高度、目标世界位置、机位侧、目标是否移动、前后动作状态和时长预算。视线匹配建立一种观看联系，不自动证明人物真实心理，也不要求对象镜头永远是严格主观镜头。本节为设计规格，实际眼神和反应时点待媒体检查。

**操作。**

1. 在顶视图标观看者和目标，在面板补高度关系。目标是人、手中物还是门外声源必须明确，不能只给“望向远方”。
2. 将世界目标投影为每镜大致方向与高低；同侧正反打先核空间，再核眼神。看镜头和看对方通常是不同任务，别用“直视”混写。
3. 安排注意被吸引、看见、接收、后续行动的顺序，留入出点余量。眼神转动不是万能替代，必要时用转头、对象运动或声音提供目标。
4. 连看人物镜与对象镜，检查同一目标是否可追踪；再正常速度看反应是否来得及读。静帧方向一致不能证明中间视线一直成立。

**原创同题示范一：坐者与站者。** 固定条件：18秒，甲坐在桌西、乙站在桌东，甲听到乙提问后抬头回答；位置、高度、原句不改，相机在南侧。原设计：甲近景被要求平视镜头，乙反打低头看画面左；两镜仿佛各对不同对象。修改设计：甲目光朝乙的世界位置向上、在南侧投影中朝画面右；乙朝甲向下、投影中朝画面左，先有提问与接收，再回答。理由：高度差和左右关系共同支持交谈。代价：甲的眼睛可能不如直视镜头醒目；若需要正面感染力，应比较合适机位，不偷偷把观看对象换成观众。实际投影以面板核对，不凭方位文字直接判通过。

**原创同题示范二：发现桌下铃声。** 固定条件：12秒，柜台下层已有一部响铃的手机，人物听到后找到它并俯身；保留物件位置与动作，不新增来电内容。原设计：人物朝高处望，切低位手机，再切人物立刻把手机拿到耳边。修改设计：铃声引起停手，人物先朝柜台下层转头并俯视；对象镜交代手机在下层架，回人物时延续俯身伸手，再按可用覆盖完成拿取。理由：声音提供诱因，低位目标、身体路线与后续行动相接。代价：需要容纳寻找和拿取，节奏比直接结果慢；若12秒不够，先缩短无效等待或保留单镜可读动作，不把手机移到台面而不修剧本/资产。

**不适用与反例。** 画外人物只听声而未看见时，不应强加对象镜冒充所见；纪录观察也可能有意不揭示目标。一次眼神偏离不能证明欺骗、爱意或某种诊断。“她看右，下镜任意物件都算她看到的”缺空间与时间依据，不能靠剪辑术语遮盖。

**练习与判据。** 固定“甲发现乙手里盒子已打开”，画看见前、目标、接收后三格，并标观看高度、目标位置和盒子状态。原始事实、机位侧和时长不变，只比较目标是否明确的一处设计。让读者指出看见什么、何时看见、反应依据；若读成看门口，先修目标方向与铺垫，不增加“惊讶”字幕。

**实际映射与回退。** 在 [continuity-plan](../../../templates/continuity-plan.json) 的角色 `pose` 描述目光/头部指向与身体进入退出状态，`prop` 固定目标持物，相机 `screen_direction/framing` 描述投影；`handles` 留真实可用的看见前后余量。[coverage](../../../templates/coverage-plan.json) 的 `screenplay_unit_ids` 关联观看、对象和反应对应的剧本动作ID。模板没有保证眼神的数值接口，实际生成须核参考、请求和take；误看回目标/机位，反应太早回顺序/切点，持续眼部变形则改景别或制作路线，不以漂亮眼部静帧替整段验收。

## 先选观看理由，再选相机运动 <a id="camera-choice"></a>

**问题与输入。** “这里慢推一下”还没说明观众为什么需要靠近。先固定剧本动作、空间、资产身份、入出状态、必要信息和时长预算，再问此刻要看清细节、发现关系、追踪行动，还是等待变化。以下是原创设计练习，无实际视频或观察时码；运动名称不证明模型能够兑现。

| 选择 | 何时有用、怎样分工 | 代价与不用的条件 |
| --- | --- | --- |
| 推进 | 注意目标已明确，动作或信息触发后靠近；写起止构图、前进路线与停点 | 可能裁掉手部或提前泄露线索；单纯放大不能代替认出、决定等行动 |
| 摇镜／回撤／侧移揭示 | 连接已知对象与原本画外或被挡的信息；分别写原地转向、后退或横移，核实际可见范围 | 新信息须已属题目；路径可能越轴、穿物或过早露出。只需两幅清楚画面时可切镜 |
| 跟移／小幅重构图 | 主体有既定路线，跟移改变机位；主体只在活动区内俯身或伸手时，可原地微调朝向 | 分开画人物与相机路线、距离、遮挡和进出方向；没有位移需求时不为跟拍另加走路 |
| 固定机位 | 同框已能读清动作、等待与关系变化 | 以人物行动和声音组织注意；若关键接点被挡，先改布局或补覆盖，不能以“克制”保留不可见信息 |

**四条设计线。** 顶视图先画人物在世界中的起止与持物路线，再画相机位置/朝向及可见侧；焦点另写看谁、何时改变，固定机位也能换焦；剪辑另写在哪里切、切后新增什么。推轨、变焦、数字裁切不是同一执行任务，焦点变化也不是相机位移。不需要换焦或切镜时明确保留。

**同题12秒：认出照片。** 一人出镜，甲看见照片里熟悉的人，压住反应并翻扣照片；门外敲两下，甲抬眼。观众须理解“认出并掩饰”，不揭露照片人物具体身份。甲坐桌北面朝南，门在东北；照片起初由右手持有。两机位均在甲—照片连线东侧，P02中门投影在画面右侧；均为稳定柔光。世界位置、照片身份、手别、顺序与声音不随备选改变。

| 镜／设计区间 | 主体、相机、焦点与状态 | 声音、剪辑和用途 |
| --- | --- | --- |
| P01／0–3秒 | 东北过左肩近景，固定；甲低头看右手照片，图面仅够辨为人像，身份细节不清。焦点留照片与手；出点仍持有 | 建立观看对象，环境底连续；在翻扣起手前切，不能切成照片已落台 |
| P02／3–12秒 | 东南中景保留脸、右手、桌面及门的位置。入点承接持物；目光停住、压住反应，右手把照片翻扣到桌中央并撤开，随后保持不动；门响后才抬眼朝画面右侧。固定机位与清楚景深，无预设拉焦 | 3–9秒安排接收与翻扣，9–12秒容纳两下敲门及回应；这是本题节拍预估，后段连续留在P02，不强加第三切。出点照片背面朝上、右手已离开，目光向门，环境底不断 |

**选与不选。** 基线保留P02固定机位：脸手同框比移动更利于检查掩饰动作。备选只在翻扣、撤手完成后缓推到仍保留照片结果的较紧构图，并在敲门前停住；其余动作、镜序、预计时长、光声不变。不选回撤/摇向门：已知敲门声足以指向门，移开会丢反应；不选跟移：甲没有行走路线。同样推近在“寻找照片细节”中可强调辨认，在“翻扣后靠近面孔”中可延长被注视感，不能据运动方向认定温情或威胁；本题不加新心理事实。

**交接与回退。** 将选择、代价和四条设计线写回原镜头描述，`duration_ms/reference_asset_ids`、入出 `pose/prop`、相机 `framing/motion/screen_direction` 与coverage承接原有字段。所需参考为东侧空间、甲脸手、同一照片正背面/翻扣状态，现未提供媒体。让消费者指出每镜注意目标、持物与切点；让固定/推进两版只改变相机，用预演查信息，实际take连播查路线、身份和接触，并记录可用区间/手柄。精确路径、焦点和停点须核当前执行器；动作不可读先回设计，输入未兑现回生成，已有可用区间先交编辑，不无限重抽。仅match_frame要求同交界帧，其他切法核声明的状态。

### 从参考观察到当前镜头结构 <a id="reference-structure"></a>

**输入边界。** 有视频时先核版本和可用范围，正常速度看听后沿真实切点记源入出时码、主体、景别、动作、相机、焦点、声音与连接。只有文章/静图时不填虚构时码、速度或音效。记录分三层：静图事实是框内可见姿态、大小与遮挡；“可能在逼近”是推断，可有变焦/裁切等解释；为当前内容安排相机前移是创作重建，不能倒写成参考事实。三格主体变大只支持构图变化，无法证明真实推轨、中间轨迹或情绪效果。

**先抽功能，再重建。** 每镜问“观众新知道什么、注意谁、删掉损失什么”，保留线索→回应→结果等抽象关系，再按当前剧本、空间与保留项重新设计。下面十二项是问题索引，不是依次执行的镜头表，也不带固定秒数、占屏百分比或镜数；缺测量依据的“结构占80%”“5秒后必崩”不作为规则。

| 检索名称 | 采用条件与执行边界 |
| --- | --- |
| 1 特写开场 | 细节可辨且有观看理由时用；环境/尺度不可缺时保留关系画面 |
| 2 反常识定格 | 分清人物停顿、固定机位与后期冻结；持帧不能替代动作因果 |
| 3 慢推逼近 | 信息触发后靠近，写清对象、起止与停点；画面变大不等于前进 |
| 4 半圈环绕 | 新角度提供必要信息才选，核背面、空间、遮挡和换侧；失败可缩路径或拆覆盖 |
| 5 俯拍转平视 | 分开降低机位与转动俯仰，核主体/背景关系；单个角度不说明路线 |
| 6 手持微晃 | 视点需要且主体仍可读时用；精细接触不默认叠抖动 |
| 7 焦点转移 | 前后目标和换焦理由明确；需核实际控制，失败可用清楚的两镜 |
| 8 速度突变 | 动作先成立，再核源帧率、音频与编辑器时间重映射；加速不能修复断裂 |
| 9 特写切远景 | 分别准备两镜，由时间线切换；不能派成单镜主体变形 |
| 10 反射构图 | 明确反射面、主体与可见范围，检查倒影；这是构图关系 |
| 11 第一人称 | 明确谁在看及其能看见什么；静止也能成立，晃动不是视点证据 |
| 12 收尾定格 | 收束/余韵/字幕确需时再选停留或冻结，声音另安排，不硬截必要回应 |

**同题落地。** 原创合成题12秒：甲看照片、压住反应、右手翻扣，门外敲两下后抬眼；一人、桌门位置、照片身份和动作顺序固定，不揭人物身份。此处没有参考视频。重建为P01三秒建立观看，P02九秒同框完成脸手动作并听门回应；时间是设计值，不是观察。不开场脸部特写，因为还需建立观看对象；不用环绕，因为背面没有新增信息；不以照片翻扣为理由自动冻结。详细相机备选见[同题选择](#camera-choice)，这里采用固定机位，将认出→掩饰→受声吸引的顺序交给剪辑消费者。

**正确承接与验法。** 原学习笔记留观察/解释及未知；镜头/coverage留当前信息、动作、相机、焦点和预计时长，continuity留身份/持物/方向，声音计划留两下敲门与环境底。编辑从实际take记录源区间和时间线位置，生成时长、可用区间、最终镜长分别记；只有设计时两类实际区间均未知。切镜、冻结、变速和声桥交给编辑前，逐项核当前工具是否支持、所需源帧/音轨是否存在；“归后期”不等于已自动实现。首尾帧/参考模式也按实际适配器核对，首尾相容不保证中间动作、遮挡或身份稳定。

让接收者从同版设计指出注意目标、四类变化各归谁、两镜接点与缺失素材，再形成原制作输入或编辑设计；能复述十二名称不算接续。结构是否清楚用相应预演/真实审阅核，模型是否兑现用实际媒体和时码核；静图或文字只能验当前设计层。构图判断不清回观察/设计，媒体缺失保留待验，输入正确而执行失败回生产；没有观众数据不声称提高完播或保证传播。
