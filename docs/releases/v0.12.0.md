# v0.12.0

本版将重点从单份文件存在推进到可核对的制作交接。操作见 [v2 指南](../guide/production-v2.md)。

- 新 Profile 固定 production-v2 规则；增加轻量单条 Profile、按集 status/next/gate、显式迁移预览／应用／备份、固定版本包审阅及返工影响报告。
- 补齐来源、分集节拍、剧本、覆盖、预演、获选素材、时间线、混音、交付与正式运行契约。来源版本、场镜覆盖、获选 SHA、声音 Cue 与交付审片贯通。
- 连续性依据明确候选与剪切策略；过滤参考变体、保留多模态角色，补充表演状态和独立声音锚点。对白绑定行 ID、表演、口型用途与实测时长。
- 正式 run 核对批准输入和 Gate，共享原生单位预算；生成后导入 draft，人审暂停后续跑。方舟轮询有界，已知任务优先恢复，提交不明不重复发起。
- 成片完整解码、音频覆盖和响度目标复检；审片使用帧区间与实际交付版本。字幕严格解析与共用样式，剪映固定支持矩阵并保留尾黑场，Remotion 固定计划和字体证据。
- 可迁移交付包使用相对清单、明确授权媒体与工程文件，移走原目录后重新校验真实媒体；私有来源默认只保留版本引用。

旧作品没有自动迁移，也没有新增作品批准、云端付费请求或外部发布。自动回归包含 FFmpeg 真实合成媒体、完整严格 CLI 链、关键帧暂停／续跑、三集独立状态及移动包复检。真实云端声音、演员口型与观众理解、Remotion 浏览器渲染、剪映 UI 保真仍需要对应制作验收；不能由合成回归替代。
