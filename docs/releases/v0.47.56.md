- **修复 AI 角色合成台与本机 AGY CLI 的生图通信桥接**（`character_studio.py`、`test_pose_gallery.py`）：
  - **移除不兼容的 `--mode auto` 参数并隔离 CLI 警告**：Gemini 订阅账号调用 `agy` 时不支持 `--mode auto` 并向 `stderr` 输出提示，原逻辑优先截取 `stderr` 导致掩盖 `stdout` 中的真实 JSON 结果；现移除 `--mode auto`，保留 `--dangerously-skip-permissions`、`--disable-slash-commands` 并新增 `--effort low` 降低协调回合耗时，同时将自定义协调模型参数修正为 `--model`；
  - **对齐 `image-generator` 真实落盘契约与多路径回捞**：适配 `agy` 内置 `image-generator` 子智能体将生成结果保存至 `~/.gemini/antigravity-cli/brain/<conversation_id>/` 的实际行为，支持从 `structured_output.saved_path`、回复文本路径、临时隔离目录及 `conversation_id` 对应 `brain` 目录安全提取生成图片（校验路径边界与图片魔数，排除输入参考图）；
  - **完善结构化错误透传与本机命令定位**：解析 `agy --output-format json` 返回体中的上游错误并映射准确状态码与中文指引（`429` 配额耗尽附预计重置时间、`422` 安全策略拦截、`401` 登录态过期），同时补充 `/opt/homebrew/bin`、`/usr/local/bin`、`~/.local/bin` 可执行文件兜底查找并将 `agy models` 在线验证超时放宽至 45 秒。
