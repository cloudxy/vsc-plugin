# v0.29.0 — Grok 剩余官方能力接通：预置声音、中段关键帧、无声视频与编辑/续接

消除 v0.28.0 遗留的三项"未接"，Grok Imagine 官方能力面全部落入 VSC 契约：

- **预置声音参考（`reference_audios`）**：平台资源 id 存放在供应商注册表的模型默认参数 `reference_voice_ids`（`provider_models.default_params`，即数据库中的平台资源 id 字段，按模型配置、随任务快照冻结），任务库适配器与脚本 `--voice-id`（≤3）共用；提示词以 `<AUDIO_n>` 指位。VSC 音频素材文件与平台 voice_id 语义不同，适配器继续拒绝把媒体文件塞进该字段。
- **中段关键帧（`keyframes`）**：供应商中立请求契约新增 `VideoRequest.keyframes`（(媒体ID, 秒) 对，追加在原位置字段之后保持兼容）；`normalize_request`／`validate_capabilities`（能力开关 `keyframes`）／worker 固定输入校验全链接线；脚本 `--keyframe 文件@秒`（≤4）。片外时间戳、间隔不足 1/3 秒、超量与经典模型使用均在提交前拒绝。
- **无声视频（`generate_audio`）**：模型默认参数布尔项与脚本 `--no-audio`。
- **视频编辑／续接**：新子命令 `edit`／`extend`（`--video` 本地文件或 https、`--prompt` 平台必填；输出跟随输入，编辑上限约 8.7s/720p）。**线上探针实证**：编辑/续接由经典 `grok-imagine-video` 承担（1.5 返回不支持）、`/v1/videos/extensions` 的 prompt 必填（422 实证）——两处官方文档未写明的行为已固化进默认模型与校验。任务库侧对既有 take 的加工继续走 media_operations 接缝，不在生成任务中混装。

离线验证：provider 11 项、CLI 16 项与相关套件共 70 项全绿；production（108）与 assets/project（206）带真实 PostgreSQL 回归通过。真实媒体的成功生成仍待小批量试产（参考模式身份一致性、占位符遵守、编辑稳定性、续接连贯性）。
