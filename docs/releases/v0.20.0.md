# v0.20.0

资产设定（`vsc.asset_bible`）出新版本时，按实体判断已批准消费者是否仍然有效，不再一律失效。

- **兼容修订**：新版本只追加参考图、实体、变体或声音，或改提示词与说明，而已有实体的 `kind`、`identity` 与已有变体的键和说明都不变。取代旧版后，固定旧版的镜头计划、声音计划、状态时间线等仍然有效，不必为追加参考图整批重审。
- **影响范围**：改动某个实体的身份或已有变体，只让文件里提到该实体的消费者失效；读不出内容的消费者从严，任何实体身份变化都会失效。被取代链的末端须是已批准的资产设定。
- 生效于两处：镜头计划对资产对象的固定绑定，以及对资产设定的依赖检查。其他产物的替代规则不变。

只运行离线测试，没有调用生成接口。
