# v0.24.0 — 场镜创作工作台与制作关系

后台默认进入创作工作台。项目概览先显示结构与数量，场镜集中呈现剧本、资产、使用实例、台词、声音、动作特效、用途候选及版本；资料之间可双向定位。PG 结构导航按需分页，候选、历史和大量资料不在首屏全量展开，搜索覆盖授权范围内尚未加载的资料。

新增不可变创作关系投影：资产使用实例与交互、剧本省略依据、专业执行及参与者／参考／用途、声音 Cue 与跨镜、字幕、口型和时间线关联。画布提供语义关系、制作来源和实际用料视图；影响报告依据固定引用列出直接／间接消费者、待复核项和未知边界。新输出继续沿既有人工选择与批准流程。

PG 试片支持同镜组相邻 1–8 镜的固定上下文；方法评测连接实际试片输出、基线、判据、环境和人工审查。跨运行、候选和方法累计同类失败，达到停止条件后需要有依据的新路线。专业武术、舞蹈、特效和声音规格进入实际制作检查；当前执行器未支持的精确控制明确阻断。

火山图片／视频增加官方 SDK 可选路线，固定 `arkruntime==0.13.0` 与运行环境摘要，关闭自动重试，复用既有预算、任务续查、未知提交恢复和媒体转存。官方 npm 发行包可检查和受控下载，验证完整性后保留版本；不执行安装脚本，封闭 CLI 仍如实标为参考路线。默认资源和在途任务不会自动切换。

已有 PostgreSQL 需显式升级到 `0005_creative_relations`；先备份再迁移。旧 JSON／SQLite 项目继续原权威并只读查询。官方 SDK 使用 `uv sync --locked --extra ark` 安装；未配置或未验证的其他供应商保持相应状态。

使用说明：[创作工作台](../guide/creative-workbench.md)、[专业创作与返工控制](../../skills/vsc/references/creative-production.md)、[火山官方路线](../architecture/ark-agent-plan-personal.md)。关系、工程规模与离线传输验证不代表真实武术、舞蹈、特效、特殊配音、生成质量或成本改善已通过人工验收。
