# v0.28.0 — Grok 能力面对齐官方规格：参考生视频、多图合成与首尾帧

按 [官方 Imagine 文档](https://docs.x.ai/developers/model-capabilities/imagine)（2026-10-17 核对）重订 xAI Grok 订阅路线的能力面，替代 v0.26.0 的最小切入范围：

- **参考生视频（reference-to-video）**：`--ref-image` 最多 14 张，提示词用 `<IMAGE_n>` 按位指认（人物来自 `<IMAGE_1>`、商品来自 `<IMAGE_2>`）；可与 `--first-frame` 组合——首帧占 `<IMAGE_0>` 并被钉定，参考图从 `<IMAGE_1>` 起编号。适合多人物身份一致、服装道具转移与商品植入镜头。参考模式分辨率上限 720p，更高分辨率走首帧模式；任务库适配器同样按 `reference_media_ids` 走该模式。
- **尾帧钉定**：`--last-frame` 可单独使用（平台生成开场并落在该画面）、与首帧组成首尾帧插值，或叠加参考图；任务库 `last_frame_media_id` 同步支持。
- **纯文生视频**：不放输入图时按官方文生视频提交；可控性弱，命令行明确提醒、不作为默认路线。
- **图像编辑／多图合成**：`image --ref`（1–5 张源图）走 `/v1/images/edits`——单图局部编辑、多图换装/风格迁移/多主体合成，提示词只写要改的内容；任务库 `image_edit` 用途经 `reference_media_ids` 走同一路径。
- **画幅**：图生视频默认跟随源图（不传 `aspect_ratio` 防拉伸）；参考／文生模式可用 `--ratio`／模型默认参数 `ratio` 显式指定。
- **负例前置**：参考模式 1080p、参考图 >14、编辑源图 >5、把音频素材塞进 `reference_audios`（官方只接平台预置 voice_id，不接音频文件）均在提交前拒绝。官方另有中段关键帧（≤4）与视频编辑/续接能力，VSC 请求契约暂无对应字段，明确记为未接。

配套：资源面板两个 Grok 预设的能力声明更新（图像 `image_edit`/参考媒体 ≤5；视频首尾帧＋参考媒体 ≤14、15 秒）；README 新增"生成供应商能力"对照表（火山 vs Grok，含验证状态）并明确授权例外；架构文档给出官方规格与实现的全量对照。离线验证：provider 模式矩阵 9 项、CLI 13 项及相关套件 65 项全绿。真实订阅账号线上生成仍待小批量实测（重点：参考模式身份一致性、`<IMAGE_n>` 指位遵守、编辑未改区域稳定性），实测前预设保持停用。
