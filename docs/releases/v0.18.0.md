# v0.18.0 · 系列对白干声离线执行链

- `vsc.series-db` 的音频任务按已批准剧本台词、覆盖镜头和人物声线固定请求；Agent Plan Seed TTS 2.0 预置音色通过统一 Provider 接口提交，结果经真实解码和 SHA 校验后转存素材库。成功转存后清理暂存音频。
- 资产库可登记带版本的发音提示；生成记录保留人物、台词行、音色和发音提示，供人工审听。当前接口尚无已验证的自动发音词典映射。
- `dialogue_dry` 按台词行选择，支持同镜多句进入选片草稿；选片仍需真实权属决定与人工批准。
- 覆盖计划只作为音频任务的固定输入，不改变既有图像／视频 ShotContext 摘要。
- 本地假响应覆盖台词校验、预算、提交、转存、记录和选片。没有发起火山方舟线上生成，也未验证完整成片或 60 集批量效果。
