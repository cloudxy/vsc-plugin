# v0.47.62

官方资产图片彻底删除时，检查所有指向共享文件的数据库引用，包括项目缩略图、预览和渲染输出。仍被使用的文件继续保留；没有共享引用的受控文件仍按原流程清理，不改变回收站和恢复操作。

在真实隔离 PostgreSQL 中复现并回归“图片仅被项目缩略图引用”的场景，验证官方图片永久删除后缩略图仍可读取，同时保留独占文件删除、并发、重复提交和失败后继续清理的测试。

另修复五项过时测试夹具与断言：历史迁移夹具只使用当时存在的表，分镜媒体使用实际用途，schema revision 和图像工具集合以当前规范为准。相关实现未因旧断言而回退；修复后的全量回归为 1798 项测试、1343 个子测试，全部通过。共享文件保护补充后运行相关定向回归。
