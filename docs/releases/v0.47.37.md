# v0.47.37

- 剧集卡片提供可点击的画布、Agent、分镜与视频入口；支持单个创建、编辑名称、增加分镜和调整顺序，沿原项目层级与事务保存。
- 画布下拉支持按创建者与名称筛选、更新时间排序、新建、重命名和复制。写入结果未知时保留原请求，恢复后继续保存本地编辑；打开新画布失败可重试进入。
- 画布可移入回收站并恢复原身份、版本与正文。回收状态同步到画布入口、发现列表与项目计数；父级回收、权限不足及关联任务进行中时保留原操作门禁。已回收画布发布的模板退出可用列表，并阻止继续收藏或复制；固定历史仍保留，独立媒体也继续可见，仅隐藏指向回收画布的失效来源入口。
- 经典分镜和视频工作台分别保存镜号选择，切换模式保留各镜草稿；主加号新增一个分镜，批量创建保留在管理入口。候选列表加载、空白、失败与分页恢复分别显示。

数据库新增显式迁移 `0052_canvas_lifecycle`。升级前先备份和验证恢复，再迁移并切换应用；已有画布回收状态时禁止直接降级到不识别这些状态的旧应用。迁移不删除旧画布、媒体或生成记录。

本次完成剧集交互、画布管理下拉与回收，以及经典工作台的部分操作。完整协作权限、画布管理弹窗、独立分镜与视频分组、专业生成设置及其余页面继续核对，尚未达到全站1:1。未执行真实供应商生成或专业成片验收。
