# v0.47.16：独立预演截取当前视窗

独立三维预演可以按当前主机位和时间下载视窗图片。已测量的 16:9 视频画幅 960×540 下载为 1920×1080 PNG，9:16 的 540×960 下载为 1080×1920。其他画幅仍按场景自己的尺寸。空场景不能截取。

这次下载只产生文件，不登记项目媒体，不创建画布节点，也不写入工作流引用。编辑器里的小预览仍是原尺寸。正式 PNG、GLB、MP4 导出仍登记为原场景尺寸的导出任务。

未被工作流引用的三维导出是否进入资产目录，现有原站记录没有证明，因此本版不把它们放进资产库。管理后台逐页一致性，以及真实供应商出片的速度与质量验收仍待完成。
