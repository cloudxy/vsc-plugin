# v0.37.0

- 新增项目 `.env` 初始化配置入口：各宿主、CLI、面板和测试自动读取既定数据库连接，无需设置 shell 环境变量；实例、账号与权限保持不变。
- 新增创作来源工作区：文案或受控文件登记、本地提取、不可变解析尝试、原文锚点、目录与人物映射、校对后导入剧本工作副本；继续使用原有提交和人工批准。
- 新增逻辑分镜设计、有序面板和镜头关系，串联固定设计版本、生成尝试和输出候选。
- 统一资产身份种类，补齐物体、生物、交通工具和植物；增加十一类资源导航与有类型的分类关联。
- 场级地点、资源需求、固定剧本行、规格、实例和用途槽位进入可查询关系；适用资源沿既有权利检查和生成输入固定，不改变历史采用记录。
- 面板按来源、剧本、分镜、资产、候选、用料组织任务入口；保留独立滚动、选中提示及简洁工作台标题。

PostgreSQL 需要显式升级到 `0010_source_resources`；执行步骤见[来源与资源工作区](../guide/source-resource-workspace.md)。扫描件 OCR、音视频 ASR 及未配置生成器保持能力缺口，不因完成登记而报告可执行。
