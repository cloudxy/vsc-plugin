# v0.26.0 — xAI Grok 订阅生成路线

新增 xAI Grok Imagine 订阅登录路线，作为火山方舟 Agent Plan 之外的第二条图像／视频生成供应商路线。凭证是本机 grok CLI 登录态（`~/.grok/auth.json` 的 key，带时效、由 grok CLI 刷新），不读环境变量；订阅授权、Grok Build 宿主授权与按量 `XAI_API_KEY` 分开识别，不自动混用或回退。

能力范围：图像走文生图（`grok-imagine-image` 系列，画幅＋1k／2k 分辨率）；视频走首帧锚定的图生视频（`grok-imagine-video-1.5`，1–15 秒、480p／720p／1080p，画幅跟随首帧，自带音轨）；不接尾帧锁定、多参考与图生文。结果 URL 临时，成功后立即转存。

接入面：

- 新增 `scripts/providers/xai/grok.py` 与 `src/vsc/adapters/providers/xai_grok/`（凭证、传输、任务库适配器、worker 工厂）。提交意图先行、断点续查不重提、共享预算按 `images`／`video_seconds` 记账，生成记录 `engine.provider=xai_grok`。
- PostgreSQL worker 改为按任务登记的供应商分发适配器（`worker_factory`），方舟与 Grok 两条路线并存；series 栈登记 `xai_grok`（登录态授权、固定官方端点）并在提交前核对登录态。
- 资源面板新增两个默认停用的 Grok 预设（图像／图生视频），按项目启用并绑定用途默认；`check` 按登录态文件报告连接状态。就绪诊断新增 `grok_image`／`grok_video` 工具行。
- 密钥定位约定更新：Grok 订阅路线的凭证位置、登录方式与授权边界写入工作区指南；文档见 `docs/architecture/xai-grok-subscription.md`。

预设默认停用，保持火山为出厂默认。截至本版本只有离线契约验证（FakeTransport 与离线 CLI 测试）；真实订阅账号的线上生成尚未实测，实测并小批量试产前不得报告该路线可用于生产。批量队列（`scripts/production/plan.py`）仍只支持方舟 image/video。
