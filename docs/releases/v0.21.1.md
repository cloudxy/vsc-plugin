# v0.21.1 — 折叠结构导航与旧素材关系迁移

- 结构导航默认收拢，展开按钮与内容筛选分开；支持键盘操作。同项目刷新保留手动展开状态，切换项目重新收拢。
- 增加旧项目迁移清单准备入口，按固定产物、真实来源、生成记录和加工证据建立类型化关系；原文件保持不变，媒体归档到受控存储。
- 兼容旧工作流的 Profile 摘要算法，不修改历史 Profile 快照或批准基线。
- 可信迁移项目保留旧固定 Profile 的 Gate 判据，多条独立计划不会被误判为互斥版本；新 PostgreSQL Profile 仍执行严格唯一约束。
- 无法建立执行关系的旧草稿明确保留为未索引历史文档；历史候选审核不自动升级为正式选片或冻结时间线。
- 本机数据库数据目录与媒体存储不进入 Git。迁移仍需备份、冻结、导入、逐项对账后才切换唯一权威。

操作见[资源面板指南](../guide/resource-panel.md)与[迁移指南](../guide/resource-migration.md)。
