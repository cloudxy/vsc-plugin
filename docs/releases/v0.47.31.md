- 营销工作室接入已取证的 114 个创意案例和 11 个分类，支持预览、概览、搜索、滚动加载及案例选择。搜索按已收录的名称、描述和分类匹配。
- 所选案例随原需求固定到原画布和 Agent 任务，保留元数据版本与摘要；目录更新或移除后，历史任务继续使用当时的案例。未选择案例的旧请求保持兼容。
- 案例选择与热门技能、商品素材和模型顺序分别保存。选择、删除、切换语言和恢复页面保留原需求及已建立任务；固定案例摘要不符时显示可读提示。

目录覆盖指留存取证窗口内的案例元数据。私有制作方法、完整视频分析、真实规划宿主及专业复刻效果仍分别验收；案例卡片或预览可用不代表生成或成片完成。
