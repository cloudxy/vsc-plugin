# v0.41.0：导演判断、动作效果与转场接续

本次将可复用方法接到原角色与固定教学读取，不增加创作阶段、批准系统或数据库结构。

- 原运镜卡补上观看目的、主体/相机/焦点/剪辑分工与同题取舍；参考观察分清可见事实、推断和当前重建，镜长、镜数及运动按内容选择。
- 原调度与特效教学补动作支撑、作用源、轨迹、接触、反馈及镜后状态；定义、设计、执行规格和提示词分别说明，单人动作和自我防护复用现有关系。
- 原动作接续教学补转场五问、声音、真实可切区间及硬切/遮挡/图形匹配边界；只有match_frame要求同交界帧。
- 明确教学摘要到正式方法产物、专业执行与run的版本接续；分层、蒙版、变速和精确动作须核实际输入与工具支持。

固定摘要、角色接收、安装资源与契约回归用于判断工程接通。真实动作、声音、审美及新输入效果需要对应媒体和实际审阅；本次教材不作为供应商效果或通用质量提升声明。既有Profile和已批准作品保持其固定依据。
