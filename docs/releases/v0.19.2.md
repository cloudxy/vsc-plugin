# v0.19.2

测试物理目录统一为 `tests/<领域>/<unit|integration|system>/test_*.py`，根目录保留运行入口、配置和说明。49 个测试模块覆盖素材、内核、知识、维护、后期、制作、项目、故事和测试工程；目录与 config v2 的 owner／layer 必须一致。原混合层级的连续性和媒体 QA 文件已拆分。

公共准备代码放在 `tests/support/fixtures/`，运行器与唯一路径引导放在 `tests/support/`。清除跨测试文件借用、逐文件目录深度推导和旧平铺入口；结构检查拒绝回到根目录、错误层级、缺少包标记及跨测试导入。

统一入口支持 `--test post`、`--test production.integration` 等范围。旧模块选择名通过受验证的 aliases 保留，具体类／方法后缀可继续选择；原 `python3 tests/test_*.py` 路径改为 `python3 -B tests/run.py --test <新模块>`。标准 unittest 递归发现仍可使用，最终 pre-push 继续运行一次全量测试。

原有 517 项测试在目录迁移后可逐项映射，没有因移动或拆分而遗漏。使用、目录及配置见[测试工程](../../tests/README.md)。
