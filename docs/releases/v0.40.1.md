# v0.40.1 — 文案审核入口与版本核对

“文案与版本”原先在只读模式隐藏审核入口，可写时又把按钮放在长正文末尾，用户难以找到下一步操作。

- 所选文案的审核栏固定在正文下方，版本列表和正文仍独立滚动。
- 批准与退回按钮在不可操作时说明原因；已启用写入的服务支持从文案就近登录，成功后刷新当前版本的审核状态。
- “核对版本”直接展开并定位版本、状态、内容摘要和最近决定；批准与退回成功后明确提示已记录。
- 读取失败、切换项目或版本时清除旧操作；缺失或摘要不匹配的内容阻止审核及局部方案入队。
- 审核按钮按用途着色：批准绿色、退回红色、核对蓝色，保留文字和键盘焦点标记。
- 本机可写工作台可配置 `VSC_PANEL_REQUIRE_LOGIN=false`，打开页面自动建立本机会话，省去登录步骤；仍保留请求来源、版本和实际决定的确认检查。

沿用既有固定版本、并发检查和人工确认接口；新安装默认仍为只读，此更新不改变数据库或 MCP 权限。回归覆盖只读、登录恢复、本机免登录及其边界、切换、读取失败与实际操作请求。
