# v0.13.0

新增 `vsc.series-db` Profile，服务 60 集以上、每集约 3 分钟的连续短剧制作。关系库成为该 Profile 的结构化权威，存剧本与批准产物的固定版本、对象关系、媒体索引、素材派生和生成任务；旧作品及其他 Profile 保持原权威，切换须显式迁移。

- 新增按镜编译的 `vsc.shot-context/v1`：从已批准剧本、风格、资产、状态、镜头和声音版本生成固定上下文，筛选当前变体，列出缺失参考，验证 SHA 与媒体权属。
- 新增媒体导入、完整解码、本地受控存储、用途绑定、人工批准和派生血缘；数据库与 `vsc.json` 镜像漂移时阻断并允许从数据库恢复镜像。
- 新增图／视频／音频统一 Provider 接口、模型能力和路由注册、离线任务计划、幂等键与状态事件。当前不含新入口的在线调度、火山方舟实测、回调／轮询或账单验证。
- 迁移和操作见 [ADR 0004](../adr/0004-series-relational-authority.md)及[数据库连续短剧指南](../guide/series-db.md)。

真实场景、完整一集、相邻两集与供应商调用留待项目脚本和人工审核。离线测试只证明状态、关系、媒体与上下文的机械约束。
