# v0.21.0 — 工程模块、PostgreSQL 资源关系与内建面板

- 领域实现迁入 `src/vsc/`，维护工具迁入 `tools/maintenance/`；52 个原脚本保留兼容入口与模块身份。测试影响图支持新路径。
- `pyproject.toml` 声明安装入口、可选依赖与规范数据，`uv.lock` 固定解析；保留 Python 3.9 核心 CLI。
- 新增 `vsc.series-pg`、59 张关系表与显式 Alembic 迁移、项目复合外键、原子关系中间表、不可变决定与当前投影。
- 内建 FastAPI 资源面板提供旧项目只读浏览、层级筛选、文案、视听预览、来源／加工／用途逆查、候选比较与人工审查操作。
- 受控存储支持本地内容寻址和 S3/MinIO 适配器；生成任务固定版本和媒体输入，未知提交不重 POST，输出转存后才成功。
- 首个人物参考／场景母版可从固定规格起步，不依赖已有自身参考；资产和镜头任务分别守剧本／预演 Gate，共用原生单位预算。
- 标准产物／对象／来源／角色任务包 CLI 接续 PostgreSQL；固定时间线可导出完整媒体包并准备现有 Remotion 工程，保留字幕、转场和样式。
- 持久预览任务记录配方、工具版本和来源摘要；租约恢复与 attempt 围栏防止旧结果覆盖。
- 迁移明确执行预览、备份、冻结、映射导入、对账与权威切换，旧项目不会自动迁移。
- `vsc-schema-review` 是架构维护子路由；资源面板属于内建应用功能。

真实 PostgreSQL 专项覆盖约束、并发、迁移、网页操作与 60 集／2160 镜／10000 素材合成规模。火山方舟线上生成和成片创作质量留待用户脚本验证；网页已验证 HTTP 行为，当前宿主未授予浏览器视觉检查权限。
