# v0.11：工程化制作、批量生产与声音接口

本版补齐从可复用规格到有界生产的执行入口，区分实现、真实调用和人工批准。

- 新增 `vsc.engineered-short`、`vsc.engineered-serial` 可选 Profile，视听设计要求声音计划、场景状态和集／场衔接；既有项目固定快照不变。
- 新增图像／视频批量计划：完整预检媒体、目录、锚点、依赖与规模预算，绑定计划 hash，串行执行并续接原任务。真实解码与原始请求复核防止错误产物被当成成功；方舟 POST 不自动重试，提交未知时停止以避免重复计费。
- 新增豆包固定 speaker 语音与 MediaKit Seed-Audio 适配器，保存请求、响应、用量及原任务凭证，验证真实音频。语音支持明确选择普通与 Agent Plan 专属地址，端点绑定请求、不自动回退。两个接口默认 dry run；不承诺分轨、精确音乐时长或仅凭 speaker ID 保证听感。
- 新增无需网络的原创程序声音：风、雨、衣物、脚步、陶瓷、钟声和简约配乐，保留参数与来源；恢复时检查请求、目标与实际 WAV 样本。
- 新增覆盖全部 20 类的原创制作规格，明确文本规格不是媒体、音色或许可；支持幂等安装、原生检索和素材库引用。公开方法增至 34 条／14 个来源，补对白、情境化表演与章节因果接续。
- 声音入库自动保留实际供应商、speaker、资源与模型，冲突属性拒绝绑定。只读工具链报告分别列实现、配置存在性、候选证据和待人审状态；本地 CI 增加规格检查。

操作见[工程化制作](../design/engineering-production.md)、[批量生产](../guide/production-batch.md)、[制作规格](../guide/asset-recipes.md)、[素材复用](../guide/reuse-and-search.md)、[豆包语音](../architecture/doubao-speech.md)与 [Seed-Audio](../architecture/doubao-audio.md)。

真实验证：豆包动物、道具、场景图各一张生成成功；七种程序声音已生成并入库。图像／视频原有本机候选可继续核验。批次异常、接口协议与恢复行为由离线回归覆盖；本版未新增付费批量视频实测。

未完成的外部验收：普通语音探测／合成及显式 Agent Plan 合成均未通过认证（401／45000010）；有效 MediaKit 凭证未配置。因此没有本版云端 TTS／Seed-Audio 成功合成证据，仍需服务开通、正确凭证及实际审听。所有新增媒体均为候选，未代替用户选择或批准，源码仓库不包含作品、素材文件或本机凭证。
