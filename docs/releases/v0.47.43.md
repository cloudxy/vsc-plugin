# v0.47.43

- 自由画布核心运行态与原位媒体精修工具补齐：新增无供应商调用的本地 Pillow 确定性图像编辑（多比例裁剪、角度旋转与水平/垂直翻转、21 款胶片/影调预设与 HSL/亮度/对比度调节、矢量涂鸦叠加）以及等距柱状 720° 全景透视截图（当前视角、4 大方位视角、12 大视角批量派生），均登记完整解码检查 `media_checks` 与操作血缘 `media_operations`，并在节点素材原位替换时强制校验宫格父图授权、模态一致性与回收站状态。
- 画布 AI 图像工具注册扩展至全部 19 项规格（新增局部重绘 `inpaint`、智能扩图 `outpaint`、智能抠图 `matting`、五维人像质感、二维情绪坐标与五官微调、多机位九宫格 2K/4K、剧情推进四格、电影级光影校正、画面推演 3s 后 / 5s 前），并补齐画布单视频入出点裁剪、多视频时间轴剪辑（500ms 防抖草稿保存与唯一音轨校验）、相机运镜预设与自定义收藏库、AI MV 歌词 LRC 时间轴对齐与分镜节点派生、IndexedDB `canvas-persistence` 本地崩溃恢复快照，以及 `/canvas` 与 `/canvas/share` 干净 SPA 路由与 `focus_node_key` 视口聚焦。
- 画布 Agent 会话补齐重命名、自动确认运行开关、归档筛选，以及待发消息队列（入队、优先插队 `steer`、取回编辑、取消）。

本版包含可逆 PostgreSQL 迁移 `0055_canvas_core_runtime`。资产中心与回收站全量交互、经典生产流及智能分镜模块仍在按分片继续实施；未执行真实供应商付费生成（`generation_jobs = 0`）或专业成片验收，不能据本版声明全站 1:1 完成。
