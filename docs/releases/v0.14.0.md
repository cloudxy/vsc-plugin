# v0.14.0

`vsc.series-db` 的正式 `production_run` 增加 `series_batch`：每项保存固定逻辑请求、候选号和原生预算单位。批准时检查镜头上下文、参考媒体、跨集边界和 animatic 依赖；计划任务只能从批准批次选取原样请求。

新增统一 `scripts/production/dispatch.py` 入口。提交前复核 Gate 与共享预算，记录不可自动重提的提交意图；异步任务按固定外部 ID 恢复查询，同步结果直接处理。成功结果转存到项目媒体库并核验 SHA，重复恢复复用已入库字节。生成媒体先标记 `unknown` 权属，新增具名权属决定后才能批准用途绑定；镜头可选择视频候选与对白干声。预算实际计费未知时保守占用，不推算货币成本。

本版回归以本地假 Provider 和真实本地媒体探测覆盖批准 run → 预算 → 提交意图 → 恢复 → 转存 → 权属决定；**没有调用火山方舟**。在线模型、临时 URL 时效、回调服务、账号限流、音频语音服务和成片质量仍未验证。旧 Profile 与已有批准快照无需迁移；新 `series_batch` 是 `vsc.production-run/v1` 的第三种互斥运行包。
