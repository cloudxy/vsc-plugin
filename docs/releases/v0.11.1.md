# v0.11.1：缺少密钥时指向本机配置

方舟、豆包语音与 MediaKit 适配器在进程读取不到凭证时，明确指出变量名、`~/.zshenv` 位置以及在启动 shell 加载并重启工具的方式。工具链就绪检查的文本及 JSON 输出也提供相同方向的提醒。

跨客户端的定位约定写入 `AGENTS.md`，操作说明见[本机密钥的位置与加载](../guide/workspace-setup.md#本机密钥的位置与加载)。工具仍只读进程环境，不自动读取或执行 shell 配置，不输出密钥，不自动更换服务凭证。已读取到凭证后的 401 继续作为认证问题报告。

回归验证覆盖缺钥提醒、无网络调用、无隐式配置读取，以及已配置时不出现缺钥提醒。没有新增付费模型调用。
