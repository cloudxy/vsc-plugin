# v0.47.41

- 自由画布与“我的项目”下的“画布”标签页新增多人协作开关、新建画布默认协作偏好及非对称工作室管理员权限模型：未开启多人协作时，工作室管理员可管理协作权限但保持画布只读，开启后工作室与项目可编辑成员协同编辑，个人空间不展示团队权限入口；每次开关决定均写入不可变审计表 `canvas_collaboration_decisions`。
- 新增一次性票据鉴权与 `sync_protocol = 2` 实时协作 WebSocket 通道，支持在线协作者头像栈与状态浮层、远端光标、按字典序升序申请的节点租约锁与单调 `fencing_token` 校验、同账号多窗口编辑 `4009` 接管下线通知，以及关闭多人协作或吊销凭据时的实时只读降级与锁清理。
- 新增浏览器侧 `canvas-async-recovery` 本地恢复存储与 `POST .../recovery/batch` 增量合并接口，自动刷新外层项目修订并合并无重叠节点修改；重叠节点并发编辑与非法端口连线分别返回 `11103` 冲突对比弹窗与 `11105` 结构化校验错误，对远端持锁节点禁用强制覆盖。

本版包含可逆 PostgreSQL 迁移 `0054_canvas_collaboration`。画布原位精修工具、资产与回收站全量交互、经典生产流及协同模块壳层接线仍在继续实施；未执行真实供应商付费生成或专业成片验收，不能据本版声明全站 1:1 完成。
