# v0.19.1

测试工程新增统一 `unittest` 入口、分层／模块归属配置、按变更文件的保守影响选择及耗时报告。修改期间可先列计划或指定受影响模块；最终 pre-push 通过 `--all` 运行全部测试，同时检查新增／移动测试是否完整配置。

公共项目与生产夹具移入 `tests/support/`；生产、正式运行和视觉检查共用单进程不可变媒体字节。Remotion 错误参数、语音规则和审片规则进入 `tests/unit/`；对应真实解码、篡改、失效版本和任务恢复检查继续覆盖。测试输出同时计数方法与子场景，不以压缩方法数代替覆盖验证。

插件与 `pyproject.toml` 版本统一为 `0.19.1`。仍支持 Python 3.9，无新增测试依赖；原测试单文件入口继续可用。当前资源面板、PostgreSQL 与业务模块拆包仍属候选提案，本次没有实施这些能力。

使用与配置见[测试工程](../../tests/README.md)，最终门禁见[维护指南](../guide/maintenance.md)。
