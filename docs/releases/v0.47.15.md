# v0.47.15：经典视频跨项目首尾帧资料库

经典视频的首帧和尾帧可以从其他项目的资料库选择固定的资产形态或已保存工作流站位图。选择后把同一份图片登记到当前项目的对应帧位，不创建目标项目资产卡，也不改画布。同一请求中断后沿原回执恢复，并把返回的媒体放回当前未保存草稿；同项目素材仍直接选用，不另建跨项目关系。

跨项目来源沿实际用途追溯原权利、共享来源及素材状态。图片仅在实际校验受控字节和完整解码后登记机器检查。该检查不代替创作质量判断。音视频和无法核验的素材仍保留技术检查缺口。

未引用的独立三维导出、管理后台与参考产品的全站视觉和操作一致性，以及真实供应商出片的速度与质量验收仍待完成。
