# v0.47.63

修复帮助中的意见反馈箱：

- “我的意见反馈”始终按当前登录身份查询，项目管理员也只在个人列表看到本人记录；管理员通过独立的“反馈管理”切换查看和处理项目成员反馈。
- 反馈类型、身份、状态、分类和搜索条件先在数据库筛选，再分页返回；提供总数、上一页和下一页，较新的其他申请不再遮住旧反馈。
- 保存反馈分类，列表和详情展示分类、提交时间、联系方式及处理历史；旧反馈缺失的分类显示为“未分类”。新增迁移 `0057_service_feedback` 不改写旧记录，有分类数据时拒绝有损降级。
- “本地审核通过”显示为“已审核”，不再误报“已联系”。处理权限、本人撤回、固定事件版本和重复提交保护继续沿用原流程。

反馈仍归属于当前项目和登录账号；本机免登录模式继续使用配置操作人的身份。
