# v0.35.0

- 剧本页可选择固定改编来源、已有场次与叙事单元，调用本机 Grok Build 生成逐行建议。调用绑定稿次与正文摘要，结果先持久化；恢复不重调用，同批独立建议可逐处接受和撤销，普通编辑仍使旧建议失效。
- PG Grok 编辑／续接固定源媒体、字节与时长，统一预算、任务输入及加工血缘；提交未知不重提，下载和登记中断可恢复。
- 工作台增加单实例规格替换、只重做本镜声音及明确新抽样：先预览目标与影响、建立待审版本，经人工批准后入队。保留原固定版本、既有质量政策与预算约束，不自动采用候选。
- 正式字幕导出绑定批准台词行、声音 Cue、采用决定、所选音频 SHA 和实测时码；烧录、Remotion、剪映消费同一包，缺行、错版本、换音频或缺测量依据时阻断。工程时码验证不等于真人语音同步听审。
- 12 个角色统一身份、权限和记忆策略；宿主提示从同一角色卡完整编译。PG、JSON、SQLite 接通记忆提案、会话确认、固定检索快照、派单消费与返回、并发和接续；fresh 审查隔离当前对象历史判断与间接来源，失效和到期事实停止下发。
- 新增 `0009_role_memory`，部署写入须显式迁移。旧 `0007`／`0008` 仍可只读查看历史状态，不自动迁移作品。生成的宿主入口不代表所有客户端已实际加载；线上媒体生成、专业声画效果与创作批准继续分别留证据。
