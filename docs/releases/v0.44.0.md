# v0.44.0：创作工作台界面与操作入口重做

工作台默认打开创作首页。管理页面采用深色侧栏、紧凑顶栏、画布主卡和工具卡；项目与分集使用三列封面目录，已有画布可按项目筛选并直接打开。分镜、视频、Agent、画布和剪辑使用独立制作页面，切换时保留当前集和镜头。

经典制作改为横向镜头条与左右生成／结果面板。空集可直接创建首镜所需的场景与镜组；参考上传留在当前页，登记完成后选入当前引用。首镜创建和上传失败保留原请求与输入，登记素材不自动确认权利或批准用途。图像／视频模式与画布深链刷新后保持。

画布工具集中到左侧浮动栏，节点编辑放在画布内，历史与资产使用浮层，Agent 使用右侧面板。剪辑使用片段列表、播放器和裁剪弹层；文字、评分、视频加工与空间工具按输入和结果分栏，技术回执与高级设置收起。独立工具入口保留所选工具，不要求先创建影视项目。

本轮按提供的有效界面截图、原样式和公开首页装饰素材还原布局；VSC 的品牌、真实账号、模型配置、权利和运行批准继续使用本地事实，不复制外站促销、积分或尚未接通的服务承诺。部分工具参考截图为空白，依据其保存的页面代码和样式实现，未声称这些页面已经逐像素对照验收。

验证覆盖同尺寸页面截图、真实 Chrome 操作、隔离 PostgreSQL 的项目／分集／首镜／画布保存及刷新接续。没有新增数据库迁移、正式作品写入或生成供应商调用。真实作品出片速度与声画效果继续按用户决定延期验收。操作说明见[创作工作台](../guide/creative-workbench.md)。
