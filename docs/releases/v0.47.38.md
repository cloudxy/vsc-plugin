# v0.47.38

- 我的项目中的画布页与编辑器中的画布管理弹窗共用画布库，支持项目、剧集、创建者、权限、更新时间筛选及搜索，按 30 条增量加载。
- 列表在服务器完成权限过滤后分页，显示实际可用操作；项目、部、剧集或画布被回收后退出可用列表。封面沿用原画布固定版本中的可访问图片。
- 管理页创建画布时选择已有项目和剧集，支持重命名、同集副本和回收。操作结果不确定时保留原请求，刷新或重新打开后可恢复；旧页面迟到响应不会覆盖新操作的恢复记录。
- 关闭管理弹窗后重新读取当前画布。未确认的管理操作会保留本地草稿并引导恢复；改名确认后可继续保存新增节点和本地名称修改。若服务器正文另有修改，保留本地稿并提示核对版本。

本版沿用 `0052_canvas_lifecycle`，没有新增数据库迁移。现有项目权限、固定版本和操作回执继续作为权威来源。

多人协作、跨集完整复制及其余页面仍在实施；相关未接通入口不会显示成功。未执行真实供应商生成或专业成片验收，不能据本版声明全站 1:1 完成。
