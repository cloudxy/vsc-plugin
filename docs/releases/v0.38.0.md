# v0.38.0：创作教材、固定方法读取与作品反馈

## 创作方法

- 原34张方法卡保持身份，15张关联六组原创教学：行动与信息、潜台词与表演、注意力与光线、调度与覆盖、声画节奏、选声与空间。每章包含同题修改、适用边界、反例、练习、实际交接与失败返回点。
- `craft show ID --with-teaching`读取完整自足章节；`--expected-sha`固定卡、来源和正文。缺失/重复锚点、越界路径及摘要变化明确失败，旧卡无教学仍可读。字符目标是软提示，不截断反例。
- Skill及角色入口接入最小任务→consume→固定读取→原产物定位应用→return。当前阶段内先探索表达再收敛，正式交接保留既有结构、版本、来源、预算和批准要求。
- 区分机器模板、草拟与原创教学，演示人物/声线/摘要不作为新作品默认值；默认小规模案例比较与扩展研究分开。

## 审阅与后期

- 剧本批注沿原行和所见版本提出一条局部建议，在原差异区接受／拒绝；恢复复用原调用，明确新一轮才新增尝试。原话、建议、决定和返回结果分别保留。
- 声音意见接原参数的单镜重做方案：预览→待审→原批准→执行→原意见回看新输出，保持原画面和用途。声线、演法等额外要求继续交专业角色处理。
- 导演设计、资产规格／实例、成片字幕／剪辑可固定版本及位置记录意见，生成专业角色任务包，沿原消费／返回协议接续；返回实际原类型产物后可回看，已有渲染输出可直接预览。派单不会自动运行外部宿主，也不会把说明当成新媒体。
- 单 Cue 位置可修改为顶部／底部／居中／自定义，固定输入摘要和整 Cue 帧范围，返回新文档与差异；Remotion、资源导出与字幕烧录消费相同布局。剪映暂不支持局部布局时明确拒绝，避免丢失修改。
- 新 `0011_review_feedback` 迁移新增7张关联／意见表，沿原批注、媒体意见、建议、任务、派单和结果记录关联，不另造一套完成状态。升级前备份数据库，执行 `scripts/project/schema.py migrate --database-env VSC_DATABASE_URL`；应用启动不会自动迁移。

## 验证与适用范围

工程验证覆盖方法读取、角色交接、安装资源及对应负例；反馈通过真实测试库、离线宿主／声音执行器和浏览器验证，文本宿主另有一次成功线上请求。单 Cue 预览用真实 FFmpeg 生成并检查另一 Cue 和音轨保持。教材和工具发布不证明作品质量普遍提高，也不自动批准项目记忆或受控能力。真实文本／媒体效果仍需固定任务、实际审阅及新输入复验。

既定数据库连接配置及MCP正式只读/应用读写边界继续沿原配置管理；真实配置、作品、私有计划和课程原始媒体不进入发布包。
