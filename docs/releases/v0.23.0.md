# v0.23.0 — 创作质量、资源配置与关系画布

创作入口按剧情、散文意象和纪实信息区分组织方式；专业交接补齐人物表演、镜头调度、资产变体、动作特效、声音与剪辑要求。必要条件、容差和偏好分开记录，规格到生成输入可用固定摘要与字段映射检查，重复失败按逻辑镜头与方法跨任务累计。

新增受范围与预算约束的预演前试片入口。试片保持候选，转正式采用复用既有选择决定并固定预演批准证据；绑定质量包的运行在生成前核验实际请求覆盖与停止条件。

新增后台全局资源配置，复用关系库注册表保存供应商、产品、套餐、调用方式、模型版本与凭证引用。编辑产生新配置快照，默认用途只影响新任务。官方工具更新采用“检查→更新／不更新”，校验失败保留旧版，运行中任务阻止切换；宿主管理工具明确标识。

新增无限画布，查询版本、素材、生成、加工、用途、时间线与渲染的真实关系，支持拖拽、缩放、小地图、搜索、上下游展开与本机布局。关系查询保留项目隔离、分页与快照版本边界。

使用说明：[资源配置与画布](../guide/resource-settings.md)、[专业创作与返工控制](../../skills/vsc/references/creative-production.md)。已有 PostgreSQL 需显式升级 `0004_trial_adoptions`（包含资源配置迁移）。工程测试与合成媒体验证不代表线上生成质量、实际费用或成片人审通过。
