# v0.25.0 — 命令目录与文件归属

命令统一归入 `scripts/kernel/`、`project/`、`story/`、`assets/`、`production/`、`providers/`、`media/`、`post/`、`knowledge/` 和 `maintenance/`。供应商命令按服务方再分目录；scripts 顶层只保留职责索引。46 个 Python 命令直接调用所属模块的 `main`，11 个没有命令行为的库转发文件已删除。

本版本直接切换调用路径，删除旧顶层脚本、模块别名层、module-map、series 动态 facade 和旧测试选择／路径别名。产品与测试直接依赖上下文、素材登记和衔接等真正拥有规则的模块。更新工作区后，命令、自动化与测试使用当前目录，例：

```sh
python3 -B scripts/kernel/catalog.py doctor
python3 -B scripts/project/state.py status PROJECT
python3 -B scripts/assets/resources.py --help
python3 -B scripts/maintenance/provider_sync.py --help
python3 -B tests/run.py --test post.unit.test_subtitles
```

技能、角色、工作流契约、Git 钩子、工具发现及安装包清单使用新路径。CI 跨职责目录逐命令定位；字幕和临时配音的独立 worker 使用新入口。测试影响分析隔离 scripts 与测试领域包的命名空间，并检查入口归属、路径逃逸和工作区外启动。安装包保留分组目录。

独立安装包补齐根说明、版本声明与派生视图。首次使用包内工作流时通过 `python -B -m vsc.kernel.hosts sync` 生成宿主发现入口，再执行 doctor；完整工作区继续通过 `VSC_WORKFLOW_ROOT` 定位。

本版本不迁移数据库，不改项目固定版本、人工决定、供应商身份或凭证规则。目录职责见[代码结构指南](../guide/code-structure.md)和[命令索引](../../scripts/README.md)。
