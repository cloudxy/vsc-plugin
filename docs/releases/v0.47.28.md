# v0.47.28：项目创建、封面与最近创作

项目创建弹窗提供名称字数、集数步进、项目类型单选和可选封面。默认类型为真人；封面通过原媒体导入上传，限制为可完整解码的 5 MiB 以内图像，并以项目内固定媒体版本保存。

创建请求保存原项目、分集批次、封面上传和打开阶段。请求失败后恢复同一操作；关闭、切页或切换身份后，迟到响应不继续写入或覆盖当前页面。最近创作读取失败时保留首页入口并提供区域内重试。

经典视频和分镜的实际编辑版本进入最近创作，链接恢复原项目、集、镜头和模式，预览只使用对应版本引用的媒体。一步新建空画布的默认名称为“未命名画布”。

本版新增显式迁移 `0051_project_cover_versions`，保存不可变封面选择及原命令回执、媒体与字节摘要关系。启动不会自动迁移正式数据库。上述改动不代表全站复刻或真实供应商出片已经验收完成。
