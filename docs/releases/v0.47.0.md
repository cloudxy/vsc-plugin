# v0.47.0：创作平台界面与资产入口阶段性升级

工作台调整了首页、项目与画布列表、媒资、资产库、文字工具和画布等页面。资产库区分项目资产、官方资产和公共素材库，跨项目资产逐页加载，并保留现有资产、媒体和项目权限边界。官方资产目录使用显式发布的固定素材版本，不将普通共享素材自动标为官方素材。

回收站可按权限分页读取已直接回收的项目、剧集和资产，恢复沿原项目命令、版本和幂等回执执行。其余尚无准确映射或独立回收状态的类别明确显示为未接入，不推断回收事实。

经典制作按模型已声明的用途与能力筛选选项；智能创作保留选片与版本，处理模型切换和阶段切换后的迟到响应。文字工具支持按成员复用独立工作区直接进入。画布新增节点选择、定位创建与小地图操作。

数据库显式迁移至 0048，新增官方资产固定版本的分类登记；迁移不自动导入第三方资产。该版本只覆盖已实现和验证的页面与操作，尚不能作为整个平台与参考产品完全一致的结论。画布多角度、打光的生成与结果回流，以及回收站其余类别仍需后续接入。

真实供应商生成验收尚未进行；离线测试不证明实际作品生成时间或声画质量。
