# v0.13.1

为 `vsc.series-db` 的统一生成接口增加第一个具体实现：`VolcArkImageProvider` 与 `VolcArkVideoProvider`。图像映射逻辑尺寸与已批准参考媒体，解析 URL 或 base64；视频保持硬首尾帧与参考图模式互斥，提交返回固定任务 ID，后续仅按该 ID 查询，解析视频与尾帧候选。`adapter_for_job()` 从任务固定快照构造适配器并复核媒体 SHA。

本版只以注入的本地假传输验证请求映射与结果解析，**未访问火山方舟**。统一执行器、预算与任务提交意图的原子交接、媒体转存、回调／轮询及在线音频适配仍需根据后续测试脚本完成。旧 `volc_ark.py` 的现有 CLI 保持原行为；它不被称为新任务表的在线执行器。
