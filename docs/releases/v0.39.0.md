# v0.39.0：作品工作台、后台字幕预览与持续制作

## 作品与待办

- 主导航整合为工作台、项目、素材库、回收站；待审文案、制作进度、已有结果围绕固定对象呈现，正文、播放器、意见与本轮结果可在同处查看。剧本、设计、候选、交付等原入口保留在专业工具。
- 工作台链接固定项目、范围、对象和版本；批量审核只处理实际勾选的固定文案，逐项返回结果。旧版本意见和结果继续可查，不覆盖新稿或隐含采用素材。
- 可写启动支持显式配置实际操作人，`vsc-panel --open` 以短时单次本机引导建立会话。默认只读启动和旧 JSON／SQLite 项目继续只读，登录不会放开原本不允许的写入。
- 只读服务直接显示浏览状态，不再提供无法使用的登录或创建提示。迁移快照、生成记录和预演技术文档保留在专业入口；超长文本按需继续显示，媒体文件引导到素材查看，避免将媒体字节显示为乱码。项目与回收站也保留各自可刷新的地址。

## 修改与后台接续

- 满足条件的样片可选择单条字幕，明确上移、下移、顶部、居中或底部，再用“修改后给我看”启动本地后台预览。原意见关联固定输入、专业执行回执、草稿计划与可播放结果，关闭页面后仍能接续。
- 首版限定已核验无字幕合成底片（clean master）、原字体及相同时间基准的固定计划；缺少这些条件时显示缺项。原素材不改写，派生预览会转码；新草稿与预览不自动成为批准或正式交付。无底片的多镜头重合成和任意剪辑没有借此开放。
- PostgreSQL `production-v2` 已授权生成任务由应用持续执行，沿原批准、固定输入、账号及原生预算账本提交。旧 Profile 保留原显式运行方式。
- 生成领取增加 owner／epoch 校验与心跳续租，旧实例不能完成新轮次；项目／供应商执行限额、公平领取、持久退避及单任务错误隔离贯穿恢复。未知提交不自动重 POST；同步或异步成功响应先持久化，转存中断后恢复原结果。
- “暂停后续制作”仅控制本次服务的全部项目，停止新提交和新的字幕预览；已提交远端生成继续追踪，不伪造取消。跨重启项目永久暂停、远端取消未实现。未知回执的人工对账使用独立已验证会话证明，不能覆盖仍活跃的 worker。
- Grok Build 文本宿主以最小环境、无工具单轮结构输出运行，保留既有订阅登录路线；不继承数据库、人工令牌或无关供应商密钥，并限制子进程时间与输出。

## 回收与升级

- 同字节重复登记可先预览影响，再逐项回收；当前采用、固定制作输入和渲染等引用受保护。恢复保留来源及历史，不自动重新采用；共享 blob 不删除，其他项目继续读取。
- 本版没有永久删除或物理清理入口；回收释放磁盘空间为 0 字节。
- 新 `0012_assisted_workflow` 迁移加入字幕编辑预览的固定输入／输出与执行尝试、渲染字幕输入、可恢复回收关系，以及生成租约轮次和调度时间。升级前备份，沿原连接执行 `scripts/project/schema.py migrate --database-env VSC_DATABASE_URL`。应用启动只检查 schema，不自动迁移；数据库实例、账号及 MCP／应用权限边界保持原配置。
- 安装包包含新执行模块、工作台静态资源、迁移与本发布说明；真实配置、作品、vendor 源码及私有计划不进入发布包。

## 验证边界

新增后台和恢复行为以真实隔离 PostgreSQL、离线供应商传输及真实本地媒体工具验证；宿主环境、超时与输出限制通过真实本地子进程检查。工程验证不产生本版线上供应商成功、真实账单、普通用户体验或专业作品质量的结论；没有新增付费服务验证。完整发布门禁和部署由本次发布记录分别确认。
