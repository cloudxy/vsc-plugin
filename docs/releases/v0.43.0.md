# v0.43.0：分集制作平台与有界快速出片

本版把项目、分集、镜头、共享资产、生成任务和剪辑放到同一管理平台。短剧按集流水制作，短视频使用六阶段轻量流程；VSC 自身维护保留独立入口。已有项目继续使用原 Profile 快照和原批准记录。

## 制作速度与结果

- 当前批次只补镜头实际使用的资产，固定角色身份和形态跨集复用。未来集需求不会阻塞本集。
- 已批准运行按依赖并行，默认最多四个 worker，并继续受供应商并发、原生用量和项目预算限制。首版目标、停止新增提交时间、尝试次数及集中修补轮次固定在运行版本中。
- 提交结果不明时恢复原任务；明确失败才允许有限新尝试。成功片段、已选资产和固定历史不会随局部重做丢失。
- 分集制作显示当前结果、实际缺项和可继续的操作。预演按需进入，完整首版优先，质量检查集中处理影响理解、人物一致性和声画可用性的问题。

## 管理与专业工具

经典图像/视频制作、引用标签和图像/视频时码标注共用原模型能力、报价、运行与候选。智能制作、二维站位、三维导演台和可执行画布将结果回到原镜头与剪辑；场景和画布保留固定版本。三维预演支持内嵌纹理、核心材质、蒙皮及动画采样；场景引用原模型文件，PNG/视频与所选时刻的静态 GLB 导出共用采样结果，格式与资源上限明确显示。

小说改编、翻译及风格库、评分、局部质检和短剧本地化保留输入与编辑稿。分组生产分别固定源区间、组内区间和目标时长，结果回流原剪辑。素材支持分片续传、部分失败恢复、固定共享库版本、跨项目导入和原任务定位。

独立文字、音乐与视频工具可先处理文件，再将固定稿或加工输出导入目标作品。跨集使用同一固定输出时复用原素材字节，来源和目标关系保留。文本宿主的已返回结果先封存到原尝试回执；操作人权限改变后仍由有权限者恢复，不再次调用宿主。歌词建议、固定音频的本地起音分析、MV 镜头与剪辑衔接、已有片段的区间替换共用原媒体与版本；算法建议和实际音视频生成分别显示。

剪辑工作稿支持裁剪、排序、分割、字幕和混音，导出 SRT、封面及含源片的可恢复工程。字幕草稿可跨轮询、切集和身份切换恢复；排队及运行中的本地合成可取消，并从同一固定版本继续。正式交付仍经过原选片/声音映射、时间线批准和冻结。项目目录、归类、回收与恢复保留原身份；永久停用保留审计，不代表物理删除或释放磁盘。

组织成员、角色、邀请、分享与审核由服务端校验。开放接口沿原用量与任务，支持明确的作用域、撤销、IP 白名单和原子限流。本地账户停用先显示归属/余额等阻碍，成功后撤销其凭据并保留作品和审计关系。

## 升级与验证边界

数据库需经备份后显式升级至 `0033_creative_tool_imports`；新增迁移扩展原 PostgreSQL 权威，不修改连接配置或旧项目内容。技术验收使用隔离 PostgreSQL、真实 HTTP/Chrome 和可解码合成媒体；生产供应商、支付、发票、短信、第三方登录与站外分发只有配置并实际验证后才可报告可用。

已验签支付回调进入原订单与结算记录；项目回收后仍可接收既有订单的迟到结果，重复通知不重复入账。固定分享清单和套餐费率在提交后不可追加。

商业套餐与额度按显式配置执行；没有支付配置不会发生资金操作。当前合同只支持未消费订单全额退款和手动续期；自动扣款、部分退款及水印权益没有完整消费者，界面不会宣称已开通，要求水印的套餐会被拒绝。

真实作品的生成速度与专业声画效果需要另外执行出片验收。本版工程验证不等于这些指标已经达标。操作路径见[制作工作台](../guide/creative-workbench.md)与[批量生产](../guide/production-batch.md)。
