# v0.17.1

简化火山凭证提示：调用火山方舟找不到 key 时，只提示配置火山方舟 Agent 版本（Agent Plan）的 API Key。

- 去掉 v0.17.0 的旧变量提示：不再维护停用变量清单，不再报“API Key 已更换”，也不再提醒进程中残留的旧变量。`--key-env` 和系列 Provider 的 `auth_ref` 不再对特定旧变量名单独报错。
- 缺少 `ARK_AGENT_PLAN_API_KEY` 时，图像、视频、语音与 Seed-Audio 统一提示：在 `~/.zshenv` 写入 `export ARK_AGENT_PLAN_API_KEY="<API Key>"`，`source ~/.zshenv` 后重启工具。显式 `--key-env` 指定的其他变量缺失时，报出该变量名并给出同样的配置位置。
- 工具诊断移除 `retired_env_names_present` 字段，缺钥指引改为同一句提示。
- 套餐规则相关的拦截不变：用 Agent Plan key 直接调用文本生成和向量化模型（视觉检查、图生文）仍会被拒绝。

离线测试覆盖缺钥提示、其他方舟变量不被读取、读取 key 时不输出任何提示。没有调用火山接口。
