- JSON 文案按字段、段落、对象和数组展示，保留完整正文、未知字段及空值。移除正文前的冗余技术头部，版本核验信息按需展开；摘要异常、精确版本批准/退回与局部方案入队仍使用原权威校验。
- 新增 `product-manager` 和 `product-designer`，在架构维护中分别负责问题与验收、信息与交互设计，复用既有角色身份、任务上下文、隔离记忆和返回协议。宿主入口统一从角色来源生成，不新增影视创作阶段。
- 架构 Skill 接入产品体验维护方法；通过固定版本的 Anthropic frontend-design、Vercel Web Interface Guidelines 和 Agency 产品/设计角色原文补充方法参考。上游源码保持本机 vendor 管理，显式按需路由，不整体打包第三方角色或动态加载 main 规则。

角色与界面变化无需数据库迁移。工程和隔离浏览器验证不代表所有官方宿主客户端已实际加载，也不替代真实作品的人工创作决定。
