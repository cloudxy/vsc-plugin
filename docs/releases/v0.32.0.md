# v0.32.0 — B3/B4 纯代码批次：字幕纯检查、审片方法门、跨镜音频去重与执行预览

§13 执行方案 B3（制作/配方/文件减量）与 B4（字幕/配音/审片）的纯代码部分落地：

- **B4-01 字幕纯函数**（`post/subtitles.py`，预览/烧录/导出共用）：`display_text()` 无标点显示派生——数字/小数/百分号/拉丁词整体保义（`3.14万元`、`5%`、`2/3` 不破坏）；`check_overlaps()` 相邻 cue 重叠/乱序；`check_coverage()` 对照剧本台词的缺字检查（空白不参与比较）；`check_layout()` 行数/宽度纯检查（等宽近似字体，无字体环境可用，与烧录同 `wrap_text` 规则）。
- **B4-03 审片方法显式化**（`adapters/media/qa.py`）：`sample-review` 新增必填 `review_method`（`tool_probe`/`ai_static_frame`/`ai_with_audio`/`human_full_play`）；严格模式（正式交付）必须 `human_full_play`——AI 静帧、含音频 AI、工具证据须另行归档，不能替代真人完整观看；`delivery_checklist()` 纯函数按方法汇总三类证据（AI 静帧永远 advisory），`formal_delivery_ready` 要求技术 QA＋真人完整观看两项在场。
- **B4-02 跨镜音频去重声明**（`story/performance.py`）：同一获选对白音频被多个时间线片段绑定时报"重复绑定"，须显式 `reuse_declared` 并给出依据——一句旁白跨三镜只对应一次用料，不再悄悄复制音轨。
- **B3-05 只读执行预览**（`production.py` 新 `preview` 子命令）：逐任务输出 `execute`（将调用平台）/`reuse`（成功记录且完成校验通过，跳过付费）/`verify`（有历史但需人工核查）/`blocked`（达 max_attempts）四态与 `usage_bound` 预计用量、缺失输入清单；不会把无产物记录虚报复用。
- **B3-04 文件减量回归**：同一计划重跑十次——生成记录恒 1 份、任务文件恒 1 份、`attempts` 恒 1、付费调用恰 1 次（journal 复用语义的量化证据）。
- **B3-01 场镜下钻收尾**：工作台镜头行新增"查看覆盖剧本行"下钻（复用既有 coverage 关系查询）。

验证：新增 `post.unit.test_subtitle_display`（显示派生/重叠/缺字/排版/方法枚举/清单门）、`story` 重复绑定正负例（声明后放行）、`production.integration.test_batch_economy`（十次不倍增＋预览三态）；post/story/assets/project 375 项与 production 286 项带真库回归全绿；模板与测试 fixture 补 `review_method`。B4-02 的 payload 参数核对、B3-03 参数差异并排展示与 B3-06 整理预览为剩余项。
