# v0.10：豆包制作、素材复用与可检索的创作方法

本版把本机案例验证过的制作能力接入 VSC 原生工具，同时保留候选、人工选择与批准版本的边界。

- 新增火山方舟适配器：Seedream 资产图／关键帧、Seedance 视频及返回尾帧、豆包视觉检查。视频默认低分辨率，精确绑定原始请求，下载失败保存用量并可续接；不会把旧任务结果记到新输入。
- 新增本机跨作品素材库，分类来自 `workflow/library.json`。素材带 SHA、权属、来源与复用记录；原始产物信息随跨作品复制保留。素材文件不进入源码 Git。
- 新增公开创作方法库和统一检索：按来源查运镜、构图、视觉、对白、表演、动作、特效、声音与剪辑方法，也能查项目对象和工作文本。
- 新增集／场衔接契约，绑定状态版本与首尾镜头，检查保持字段和有理由的变化；登记产物时复验项目对象及状态版本依赖。
- 修正跨镜检查：实际返回尾帧优先；同一图像可对应多个镜头边界；失败、非法或跨项目记录不作为身份依据。视觉检查必须保留逐项依据与完整清单。
- 本地 CI 增加素材库及方法库检查。新的契约与阶段路由在内核注册。

新命令用法见[素材复用与检索](../guide/reuse-and-search.md)，供应商配置及限制见[生成适配器](../architecture/generation-adapters.md)。现有 schema 3 项目无需迁移，固定 Profile 和批准记录保持原有语义。新可选契约不会自动成为旧项目 Gate；视觉检查提供提醒，不构成批准。

边界：豆包图像和三镜视频链已有本机实测；适配器的故障、重试、绑定与清单行为由离线回归测试覆盖。稳定角色语音、专用 TTS／音乐生成、3D、向量检索、队列及完整成本账本尚未接入。公开方法未被当作已批准项目能力；跨集检查验证声明与状态，不证明故事质量。
