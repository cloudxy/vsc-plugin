# v0.47.40

- “我的项目”下的“媒资”标签页升级为跨项目只读媒资目录，支持按可读 PostgreSQL 项目、剧集、六类创作来源（三视图、分镜首帧、合成视频、画布图片、画布音频、画布视频）以及双月起止日期（含今天、昨天、前天、本月、上月快捷筛选）组合过滤。
- 列表采用 20 条分页与去重续拉，16:9 模糊同源背景卡片如实展示媒体预览、真实时长与尺寸；未知宽高、未知或零时长、未分类或多重归属素材不伪造角标与 `00:00` 数值。
- 图片预览采用全屏序列灯箱（自动跳过音视频）与可折叠 360px 详情侧栏，音视频采用独立预览弹窗并在标签页隐藏或离开时自动暂停与卸载缓冲；跨项目查看来源、下载与经典工作台固定草稿“复用配置”均严格绑定单条资源的所属项目权限与固定版本快照，不隐式创建分享链接或生成任务。

本版保持 `0053_canvas_direct_copies` 数据库结构不变。自由画布多人协作、资产与回收站全量交互及其余页面仍在继续实施；未执行真实供应商付费生成或专业成片验收，不能据本版声明全站 1:1 完成。
