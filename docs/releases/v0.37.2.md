# v0.37.2

项目配置统一归 `config/`：本机初始化配置和模板分别位于 `config/.env`、`config/.env.example`，公共默认值仍为 `config/default/settings.toml`；本机 MCP 连接定义与示例归 `config/mcp/`。加载实现仍属于 `src/vsc/configuration.py`，启动器、运行数据与验证证据仍属于 `.vsc-local/`。

根目录 `.env` 不再作为默认读取位置，也不提供隐式回退。已有本机文件按原字节迁移，保留连接值与权限；使用旧版本的工作区升级时将 `.env` 移至 `config/.env`，将本机 MCP 的连接与示例目录移至新归属，并将 `.vsc-local/database-mcp/launch.py` 的 `--config-folder` 参数同步指向 `config/mcp/connections`，随后重启工具。五宿主的共享 `start` 路径保持不变，无需重复登记服务。真实配置仍受忽略与提交检查保护，安装包只包含配置说明、模板和公共默认值。
