# v0.40.0：有效成果交接与紧凑工作台

## 创作与交接

- 总编排和专项技能明确本轮问题、保留项、实际成果及接收者；补充镜头设计、参考资产、剪辑修改的原创正反例。候选探索和恢复记录仍有价值，文件数量不作为质量指标。
- 原角色任务包可固定 `vsc.role-delivery/v1` 用途约束，CLI `context build --delivery` 与自动意见派单共用。返回检查受控产物的正文、类型、契约、固定摘要、输入关系及范围；没有成果时保留任务并说明缺项，接续继承原用途。
- 新候选不要求先获批准才能返回；历史任务保留兼容。登记、任务结束、用途检查、人工采用和实际消费分别表达，没有新增批准关卡或独立完成状态。
- 技能、产品及设计角色入口按职责接入原参考；宿主入口由原生成器同步。方法读取与合成角色接续仅证明方法在该样例被使用，不代表专业效果提高。

## 制作结果与审阅

- 生成完成时核对实际媒体类型，视频任务必须有真实视频输出，单独缩略图不能完成视频任务。沿原存储核固定字节及完整解码证据；已有同字节检查可复用，转存失败沿原响应恢复，不重复提交生成。
- 字幕预览核实际画幅、时长、音轨覆盖和固定配方。读取时检查本地副本是否存在、可读且大小匹配；原意见区和任务轮询使用同一检查。打开内容时仍核固定摘要。
- 缺失媒体保留成功回执、意见及历史，同时显示具体缺口；浏览器播放失败提供重读入口。执行成功但无输出、空建议或仅有完成摘要均不再显示成可回看的成果。
- 可解码不等于表演、人物、声音或剪辑质量合格；结果不会因此自动采用。

## 工作台

- 标题、项目范围与右侧专业工具、刷新采用紧凑布局。
- 专业工具按创意与原稿、剧本编辑、场镜设计、候选比较、剪辑交付的顺序组织；关系与版本工具另列查阅组，避免把辅助工具混进创作顺序。
- 保留正文、列表、意见独立滚动与选中关系；窄屏使用单区域切换，菜单可滚动、键盘可退出，长标题和范围可换行。

本版沿用 `0012_assisted_workflow`，不增加迁移，不改变数据库连接、MCP 只读或应用读写配置。工程验证使用隔离测试数据库和合成媒体；真实作品的完整观看、听审和专业效果比较仍需相应创作输入与审阅证据。

用法见[角色上下文 CLI](../guide/cli.md)和[资源面板指南](../guide/resource-panel.md)。
