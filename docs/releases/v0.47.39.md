# v0.47.39

- 画布库增加“复制到其他分集”的双列项目与分集选择器，支持已有项目间复制。目标只显示当前会话可编辑的项目，源画布所在分集从同项目目标中排除。
- 复制固定画布版本中的节点、连线、布局、已选媒体，以及关联的调度、剪辑和工具草稿。副本使用新的对象标识并保留可追溯的来源；复制不提交生成任务，也不复制执行或批准状态。
- 已提交但响应丢失时按目标项目恢复原操作回执。列表读取失败只重读结果；目标版本明确冲突后可重新选择发起新操作。跨项目副本即使不在当前筛选范围，也可从结果提示直接打开。
- 媒体复制检查实际字节、当前使用权限及来源链。尚未结束的任务、未选择的多个输出、目标已有剪辑稿等冲突会明确提示，不覆盖已有内容。

本版新增 0053_canvas_direct_copies：固定复制记录、媒体映射与领域对象映射采用关系约束，并与原项目版本和操作回执共同封存。旧模板复制继续使用原入口、回执与历史记录。

多人协作及其余页面仍在实施。未执行真实供应商生成或专业成片验收，不能据本版声明全站 1:1 完成。
