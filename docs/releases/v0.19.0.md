# v0.19.0

状态时间线（`vsc.scene-state/v1`）新增两个可选的逐镜字段，锚点包不再把画外在场的实体写进画面描述。

- `shots[].location_id`：只覆盖该镜地点，用于场内一镜在别处或闪回；人物与道具状态仍沿场推导。须是资产库中的地点。
- `shots[].in_frame`：入画实体 ID 数组，每项须在该镜在场。写了它，锚点包只给入画实体的外观与状态，本镜变化也只保留入画实体；画外在场者只以编号和名称列入 `off_frame`，锚点文字写作「画外在场、不得入画」。声音锚点不过滤，画外的人仍可被听见。
- 未写这两个字段的时间线，推导结果和锚点包哈希完全不变，已有生成记录不会被判为过期。

只运行离线测试，没有调用生成接口。
