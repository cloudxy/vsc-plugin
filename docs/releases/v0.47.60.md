# v0.47.60

官方资产详情按顺序展示主图、备份图-1、备份图-2；点击列表图片进入详情，每份图片可放大、引用或加入项目。图片左上角提供删除按钮，确认后移入回收站。

回收站新增“官方资产图片”，支持预览、恢复和确认彻底删除。删除会阻止原成员的内容访问、下载与新增引用；固定版本和操作审计保留。彻底删除清理独占的受控文件，其他资产或项目共用的字节继续保留，界面明确反馈。文件清理失败可用原请求重试，不恢复已永久删除的成员。

新增显式备份关联及媒体生命周期迁移 `0056_library_media_lifecycle`。关联固定库版本与成员，不按名称猜测，不修改已发布快照。

验证：真实隔离 PostgreSQL 与 HTTP 覆盖删除、恢复、独占文件清理、共享引用保护、权限、重复提交和并发冲突；浏览器走查主图/备份图编号、软删除、回收站恢复及恢复后详情。供应商生成未新增调用。
