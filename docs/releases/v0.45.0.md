# v0.45.0：制作操作、公共资产与原任务数据流贯通

经典制作在当前镜头完成保存、报价、提交、候选查看与工作选取。上传参考可直接进入本次生成，不必先跳转到正式采用页面；工作选择与正式创作批准分别保存。恢复原请求不会重复提交，已成功镜头不因其他镜头失败重做。

项目资产新增稳定身份、独立形态、主图、音色、收藏、用途和分集别名；跨集共用原媒体，跨项目复制保留来源与目标映射。项目支持创建初始镜头、插入和分页移动分集。智能制作把阶段表格、缺项生成、站位候选与导演台回流放到当前任务。

画布连接文字、媒体、空间、剪辑和声音的原领域对象；结果可以返回原画布，附件和恢复请求随原任务保存。音乐、配音、配乐混合与 MV 段落进入原媒体及剪辑工程。小说和文字工具新增可接续批次、媒体理解、编辑确认、资产注册回执及分组视频合成。

剪辑播放器同步画面、声音和字幕，支持裁剪、分割、淡入淡出、选中片段下载与固定工程包。任务中心和个人通知指向原任务，区分部分成功、失败与回执未知。共享画布使用同一编辑器，团队页面显示工作空间名称、项目与资源，组织额度分配和回收沿原账本。

原生媒体工具增加独立蒙版重绘、全景与交互浏览、4K/8K 超分、灰度深度视频及其后继动作任务、歌词演唱歌曲。数字人可先识别讲话主体或手绘主体蒙版，再固定人物、音轨和表演说明生成。480p 视频草稿可按原供应商任务升级至 1080p，分别保留报价、任务和结果。各路线按实际供应商能力与独立凭据启用。

画布 Agent 保留有序模型列表，显示不适用原因，并支持一次明确启用的任务数、时长、费用和截止时间范围。三维对话默认直接保存可编辑场景版本，也可选择先审计划。制作顶栏可切换项目和分集，剪辑按镜号显示本集全部视频候选，最近创作和项目卡使用真实封面、类型与计数。

账户增加邮箱、手机验证码与 OIDC 登录，复用原身份、个人空间和权限。通道默认停用，启用前须配置相应服务。界面支持 27 种语言切换并保留当前输入；中文和英文覆盖软件专用说明，其他语言的专用说明明确回退英文。

数据库从 0033 增量升级至 0046，新增工作选择、资产形态与来源、文字工具固定输入、画布附件、组织账目、供应商资产注册、社区固定内容、个人通知、场景生成意图、认证挑战与个人候选收藏关系。旧正式采用、媒体、生成请求与项目身份保留。数据库升级需要显式迁移；运行中的旧版本与新静态文件不能混用。

验证使用隔离 PostgreSQL、真实 Chrome 操作和可解码的测试音视频；供应商协议、登录发码、支付、开票、分发和注册使用隔离适配器。没有执行真实作品的新一轮生成，也未据此声称实际出片耗时或专业效果已达标。没有启用的外部服务会显示具体缺项。

操作入口见[创作工作台](../guide/creative-workbench.md)。
