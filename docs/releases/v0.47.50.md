# v0.47.50

- 官方资产「服饰」浏览首屏速度与滚动续载优化（`costume_gallery.py` / `asset_center.py` / `app.py` / `asset-center.js`）：
  - 将服饰默认分页与下滑续载步长由 `120` 张统一调整为 **`24` 张/页**，首屏前 8 张立即加载、其余卡片与后续分页采用懒加载 + 异步解码（`decoding="async"`），避免大量高清 PNG 同时占满 Safari 同源连接池与主线程解码队列；
  - 将底部 `IntersectionObserver` 绑定至实际内层滚动容器 `.workspace`（`rootMargin: 0px 0px 480px 0px`），向下滑动接近底部自动平滑续载下一批 24 张，切换分类时重置滚动位置并在切换/卸载/加载完毕时自动 `disconnect()`，同时保留底部「更多」按钮兜底；
  - 新增服饰目录与侧车元数据的自动失效内存索引缓存（`cached_costumes`），消除 `/api/v1/asset-center/costumes/{item_id}/content` 每张图片重复扫描全部目录与 JSON 侧车文件的开销，并为服饰图片文件响应补充 `Cache-Control: private, max-age=3600`（其余接口与错误响应保持 `no-store`）。

未执行真实供应商付费生成（`generation_jobs = 0`）或专业成片验收。
