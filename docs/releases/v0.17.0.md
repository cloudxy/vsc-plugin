# v0.17.0

火山引擎凭证统一为一把方舟 Agent Plan 专属 key。

## 行为变化

- 方舟图像／视频（`scripts/providers/volcengine/ark.py` 及系列任务适配器）、豆包语音（`scripts/providers/volcengine/speech.py`）、MediaKit Seed-Audio（`scripts/providers/volcengine/audio.py`）统一只读 `ARK_AGENT_PLAN_API_KEY`。共享规则在 `src/vsc/adapters/providers/credentials.py`。
- `HUO_SHAN_API_KEY`、`ARK_API_KEY`、`DOUBAO_SPEECH_API_KEY`、`DOUBAO_MEDIAKIT_API_KEY` 停用：作为 `--key-env` 或系列 Provider 的 `auth_ref` 时直接报“API Key 已更换”；进程只带旧变量时说明缺新变量；新旧并存时只读新变量，并在每个进程提示一次旧变量已不再读取。
- 方舟图像／视频默认改走套餐专属地址 `https://ark.cn-beijing.volces.com/api/plan/v3`。官方快速开始写明 Agent Plan 须用专属 Base URL；图像和视频接口在该地址上的具体路径尚未实测，可用 `ARK_BASE_URL` 改为 `https://ark.cn-beijing.volces.com/api/` 下的其他路径。
- 豆包语音默认 `--service agent-plan`；普通语音须显式 `--service speech` 并用 `--key-env` 指定其他未停用的变量。
- 官方套餐规则写明文本生成与向量化模型不可用于 API 调用，在非 AI 工具中使用套餐 Base URL 与 Key 可能导致订阅停用或封号。因此 `scripts/providers/volcengine/ark.py inspect` 在预留预算和写提交意图之前就拒绝新提交，只能预检和读取已有报告；视觉检查的正式运行包也在预留额度之前拒绝执行，已批准的旧运行包与已导入报告不因此失效；`call()` 也拒绝任何对话、Responses 与向量接口。工具诊断把视觉检查标为 `blocked_by_plan_rules`。

## 验证与边界

离线测试覆盖旧变量提示、残留会话提示仅一次、密钥值不回显、套餐地址与地址白名单、文本模型拦截不留尝试记录和预算占用。**没有调用火山接口**：这把 key 能否在套餐地址上生成图像、视频、语音和 Seed-Audio，以及脚本直接调用是否符合套餐对“AI 工具”的界定，都须用户确认并实测。已有生成记录与任务文件中记录的旧变量名属于历史证据，不改写。
