# v0.47.17：预演正式图片按实测静帧尺寸登记

独立预演导出的 PNG 按已测量静帧尺寸登记。16:9 视频画幅 960×540 的图片为 1920×1080，9:16 的 540×960 为 1080×1920。其他画幅的图片仍按场景自己的尺寸。MP4 与 GLB 仍使用场景画幅。空场景不能登记导出。

导出面板显示当前视频尺寸和对应 PNG 尺寸。截取当前视窗仍只下载文件，不登记媒体。正式图片导出登记为项目媒体，场景文档本身的画幅不变。

未被工作流引用的三维导出是否进入资产目录，现有原站记录没有证明，因此本版不把它们放进资产库。管理后台逐页一致性，以及真实供应商出片的速度与质量验收仍待完成。
