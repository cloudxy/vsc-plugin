# 固定批准版本与受控方法试用

VSC 保存登记时的独立产物快照，批准与下游消费共用内容、契约、范围和依赖检查；工作文件后来修改不会改变已批准版本。项目固定 Profile 内容，本机命令在读取状态前取得锁，避免并行角色互相覆盖。

这一选择保留人工创作批准，同时把“批准了什么”变为可检查的证据。代价是额外磁盘占用和显式新版本登记；不采用“跟随工作路径最新内容”的隐式基线。方法试用与评测绑定这些版本，跨项目只迁移人工去项目化的方法，新项目不继承批准结论。

锁仅覆盖本机 CLI；这不是分布式队列、权限认证或自动审美判断。Profile 快照固定业务规则，不冻结 Python 校验器、生成模型和全部第三方环境；这些仍需要独立记录版本和验证。
