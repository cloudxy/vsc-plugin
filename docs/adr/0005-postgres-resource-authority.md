# ADR-0005：PostgreSQL 资源关系、工程模块与内建面板

- 状态：已采纳（2026-10-15，用户批准实施工程升级方案）
- 前序：[ADR-0004](0004-series-relational-authority.md)
- 操作说明：[资源面板指南](../guide/resource-panel.md)

## 决定

新增 `vsc.series-pg` / `postgres-series-v1`，固定项目可包含多部，部包含集，集包含场，场包含序列，序列包含镜。单部项目可在界面折叠部层；既有项目不自动补造层级。

PostgreSQL 保存事实与资源关系，受控本地存储或 S3/MinIO 保存二进制字节。blob 与项目内素材登记分离；用途槽位、候选、人审、选择、来源、加工输入输出、任务输入与时间线用料分别建表。项目内外键包含项目 ID。不可变正文与关系投影通过摘要和版本绑定，投影不成为第二个编辑入口。

正式选择在同一事务锁定项目 revision，写不可变决定并更新当前投影。当前产物投影切换不撤销旧版批准和历史消费者。候选拒绝、用途退役、素材停用分别记录；不经面板删除文件。人工作决定必须来自真实操作人，AI 技术检查不能批准素材。

旧 JSON/SQLite 项目继续原权威；面板只读。迁移采用 preview→backup→freeze→import→compare→cutover，缺少映射或证据时阻止切换，不猜测目录与用途关系。PG 不可用时不回退旧镜像；切换后旧入口拒绝写入。切换需要逐项目明确执行，启用面板不会迁移作品。

领域实现放 `src/vsc/`，维护工具放 `tools/maintenance/`，`scripts/` 保留兼容入口。CLI、网页、AI 使用同一资源应用接口。规范 Gate 与 Profile 快照继续固定；网页不另设批准权威。

Provider 统一接口继续有效。生成消费者读取已固定的输入版本、素材与选择决定；提交结果未知时保持未知，不自动重 POST。输出立即入受控存储，供应商临时 URL 仅作来源留档。

## 代价与验证

增加 PostgreSQL、迁移和网页可选依赖；传统标准库 CLI 仍可单独运行。真实 PostgreSQL 验证复合外键、事务并发、迁移、关系逆查及合成规模数据，SQLite 不替代该验证。线上生成及成片质量由用户脚本验证，离线工程测试不代表 60 集质量通过。
