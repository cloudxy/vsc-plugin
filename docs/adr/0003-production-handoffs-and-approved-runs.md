# ADR 0003：制作交接与正式运行

- 状态：已采纳，v0.12.0。
- 依据：[2026-10-11 审查](../plans/2026-10-11-vsc-workflow-review.md)。

问题发生在已有模块的接缝：单场计划被误当整集覆盖，成功候选被当成选择，时间线与实际媒体版本脱离，低层队列缺少正式批准入口。保留现有内核、项目锁、固定快照和生成恢复，补齐跨阶段交接契约及正式运行协议。

采用 production-v2 固定 Profile。旧项目保留历史快照；显式迁移展示差异、失效与备份。新交接契约直接引用登记版本和真实 SHA，已有渲染帧语义只在 timeline 内包装一次。来源快照与原工作路径分开，私有原文不自动进入交付包。

将计划、批准、执行、候选、选择分开。production-run 是人工审阅产物，运行前核对 Gate、输入和共享预算；关键候选暂停等待真实决定。资产准备在 script Gate 后运行，镜头制作在 animatic Gate 后运行，避免资产与预演形成环。成功导入保留 draft，选择由 selected-takes 批准表达。

预算使用平台原生单位，未知费用保持未知；不因本地生成成功推算货币。完整解码、声音覆盖和结构化审片记录共同约束交付，人工审美不由机器替代。

代价是增加机器索引与验证。以轻量单条 Profile、固定版本审阅包和单次操作 DAG 校验缓存减少重复；缓存不跨命令保存，不跳过下一次 SHA 复查。规则、字段和操作分别见 [制作协议](../../workflow/production-v2.md)、[契约目录](../../workflow/contracts.json)、[使用指南](../guide/production-v2.md)。
