# 资源配置与官方更新

资源面板顶栏的“资源配置”是全局设置，使用与素材面板相同的本机操作会话。配置保存在 PostgreSQL 的 provider/model/route 注册表中；没有数据库时显示只读预设。已有数据库先按 [关系模型指南](resource-schema.md) 显式升级迁移，再启动面板。

升级前保留数据库备份；确认没有在途任务后执行：

```bash
.venv/bin/python -B scripts/project/schema.py migrate --database-env VSC_DATABASE_URL
```

随后重新启动面板。迁移仅增加配置与试片采用关系，不把已有候选或创作决定改为批准。

## 模型与默认用途

一项配置分别记录供应商、产品、套餐、区域、调用方式、模型及版本、能力、默认参数和凭证环境变量名。页面不接收密钥值。火山资源使用 `ARK_AGENT_PLAN_API_KEY` 与 Agent Plan 端点，变量加载方法见 [工作区设置](workspace-setup.md)。

1. 选择供应商预设，填写实际可用的模型标识、版本与用途。模型能力必须以供应商文档和实测为依据。
2. 保存后执行“检查配置”。此检查只核对配置与当前进程中的凭证引用；“查看已登记模型”只读取本地注册表。这两项均不发起付费生成，也不证明远端权限或生成质量。
3. 在“默认用途”中选择已启用且用途兼容的配置。默认值用于未显式指定模型的新 PostgreSQL 任务；固定任务保持原模型、连接和参数。
4. 编辑会创建不可变的新版本并停用旧版本，须明确重新绑定默认用途。停用或选择“不设置默认”会解除默认绑定；旧任务的恢复、轮询仍使用原快照。

目前已接通火山 API 的图像、视频和固定音色配音路线，以及 xAI Grok Imagine 订阅登录路线（文生图与首帧图生视频；凭证为 grok CLI 登录态 `~/.grok/auth.json`，不填凭证环境变量，端点固定 `https://api.x.ai/v1`）。Grok 预设默认停用，启用后先小批量实测再绑定用途默认。音效、配乐、官方 CLI/Skill 执行器，以及阿里、OpenAI API 适配未接通的配置只能停用保存。OpenAI 宿主图像工具属于宿主管理，与自有 OpenAI API Key 分开识别；Grok Build 宿主工具与 Grok 订阅 REST 路线同样分开识别。保存配置不代表供应商已经可用于生产。

## 检查 → 更新／不更新

“官方更新”页先检查上游固定版本，再由一次“更新”点击执行下载、校验和切换；“不更新”保留现版。没有二次人工审核队列。失败会保留或恢复旧版；在途或结果未知的任务阻止切换，以免改变运行中的工具。

同一入口也提供命令行：

```bash
python3 -B scripts/maintenance/provider_sync.py check --tool volcengine-ark-cli
python3 -B scripts/maintenance/provider_sync.py update --tool volcengine-ark-cli --revision FULL_COMMIT --actor ACTUAL_OPERATOR
```

`FULL_COMMIT` 使用检查结果的完整提交号，操作者填写真实身份。数据库连接默认读取 `VSC_DATABASE_URL`。脚本不会执行候选源码、安装 npm CLI、发起模型测试或自动更新宿主工具。

Ark CLI Skills 源码来自登记的官方 Git 来源。其他已登记 Vendor 来源明确标为第三方，不能因出现在同一页面就称为供应商官方工具。远端下载不可达、来源变化、校验失败或存在运行任务时，修正原因后重新检查；不能把检查失败视为“没有更新”。

## 素材关系画布

项目页的“无限画布”位于“登记素材”后。它投影已登记的来源、文案版本、生成输入输出、加工、候选、当前采用、时间线片段与渲染关系。候选与当前采用分开显示，停用或替换素材的历史剪辑关系仍可追溯。

拖动空白平移、滚轮缩放，拖动节点整理位置；小地图与“适应范围”用于导航。搜索限于当前已加载节点，素材卡片的“在画布中查看”可直接定位未加载素材。“上游一层／下游一层”读取关系，“突出上游／下游”高亮已加载的路径。点击节点或连线查看事实，素材和文案节点可打开原详情。

按用户、作品和对象范围保存的本机布局只包含几何位置和不透明 ID，不写入正文、不改变制作关系或批准。刷新后仍使用当前权威数据；版本冲突会要求重新读取。查询有节点、边和深度上限，截断会明确提示，可翻页或继续展开。旧 JSON 项目只显示有明确登记依据的关系，并提示索引缺口；不根据文件名推断制作链。

试片素材及其已登记加工产物在正常“选择此候选”表单中显示预演版本选择。正式采用时选择已批准预演，并在同一决定理由中说明采用依据；沿用原有一次确认，不另设审批页面。参考用途仍可供受控试片使用。
