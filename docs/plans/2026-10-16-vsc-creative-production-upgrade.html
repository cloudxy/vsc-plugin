主线 A

哲学思想如何真正指导创作和工作流

指导问题思想视角具体创作决定在流程中的落点
这部作品为何值得做？价值论、伦理学、美学表达、审美、受众体验、商业目标如何排序；哪些不能牺牲复用创作委托与冲突裁决，目标贯穿审片
我们理解了原文什么？认识论、诠释学事实、人物说法、解释、改编和未知分别是什么；局部与整体是否一致固定来源、可回查定位、备选解释与删改理由
人物为何这样行动？存在主义、德性与关怀伦理欲望、需要、选择代价、关系与行动后果人物弧、场景任务、表演节拍；非人物中心作品按需省略
观众如何形成理解和感受？现象学、符号与叙事研究视点、信息揭示、画面线索、声音、停顿与节奏体验意图连接具体场镜及真实观察
谁有行动权和解释权？批判理论、女性主义及跨文化视角叙述立场、凝视、被忽略的声音、文化语境和刻板表达改编与审片时有针对性地检查，不设统一政治或审美答案
怎样知道方案有效？实用主义、可批判的探究比较方案、先定假设、寻找反证、保留不确定性预演、实片试制、观看反馈与方法修订
局部决定如何影响整体？系统思维结构、制作能力、时间成本、依赖、反馈与瓶颈影响分析、批次安排、返工归因与跨项目复验

这些是设计转化，不把哲学当作自动创作公式。价值排序可能冲突：先按项目的不可牺牲条件和优先级筛选，再比较表达、成本与风险，负责人决定真正的取舍。

A2 · 自动拆解需要覆盖的专业内容

自动拆解分三步：从原文提取可回查内容；提出改编与视听方案；在批准后形成可执行规格。原文没有写出的机位、精确表演和声音选择属于创作提案，不能伪装为提取到的事实。

主题与结构核心命题、视点、类型、主副线、铺垫与兑现、信息控制、戏剧反讽；散文对应意象、联想、段落与情绪结构
人物与关系稳定身份、欲望与需要、价值矛盾、能力与限制、关系变化、人物弧、当下知道和误信什么
场次与节拍场景功能、进入／离开状态、行动与变化、信息增量、节奏、时长、与前后场关系；段落可按创作形式替代传统场景

场面调度人物站位、进出路径、空间占用、遮挡、道具交接、动作与相机配合；相机动、主体动、剪辑变化分开设计
美术与环境场景平面与可拍方向、建筑材质、陈设、昼夜、天气、季节、服装妆发、伤妆、动物、交通与时代一致性

剪辑与连续性主要动作、反应、插入及必要补镜的覆盖；动作接点、头尾余量、情绪／信息连续性、J/L cut、转场用途与实际使用区间

A3 · 从输入到成片的操作流程

阶段自动化承担交付与人工决定
委托与输入识别内容类型，整理目标、范围、来源和不确定项创作委托：确认受众、表达价值、形式、预算、时长与边界
理解与改编拆解来源、交叉核对人物与时序，提出有限改编选项故事／意象底稿、改编契约、结构与删改理由；确认创作方向
剧本与表演在批准方向下写场次、动作、对白、声音及节拍，试读估时可表演剧本及表演意图；确认人物、表达与台词基线
视听与资产设计编制镜头、调度、声音、资产与覆盖；提出能力、成本及替代方案分镜／资产／声音／制作路线；确认核心风格与规格
资产准备与预演在已批准规格与授权内制作必要母版、临时音轨、预演及有限难点试片看得见、听得到的预演和方法证据；确认批量制作基线
正式制作按固定输入编译请求，调用已验证路线，登记候选、检查缺陷与用量候选及检验结果；按人工选择或已有明确委托确定用途，不自行扩大授权
粗剪与精剪用已选素材建立局部粗剪，检查节奏与衔接，完成声音、合成和调色实际成片版本、用料与缺口；修改按原因回到最早责任环节
终审与交付真实媒体技术检查、版本打包与可编辑工程整理人工审看表达与整体体验，确认交付；外部发布另按既有授权
复盘与方法更新汇总质量、成本、返工与反馈，提出条件化方法修订人决定保留、试用或退役；不因单次成功自动推广

制作路线可按镜头选择 AI 生成、实拍、二维／三维制作或混合合成。实拍路线补充演员与场地安排、排期、服化道、机位与灯光、现场收音、场记及素材备份；具体摄制依赖实际人员和设备。三维路线按需增加模型、材质、绑定、动画与渲染。现阶段这些作为规划及接入范围，不宣称所有路线都已有执行工具。

上述流程是现有阶段的专业化细化，不新增九轮独立审批。相关产物可以合并为固定版本审阅包，复用已有 Gate；用户确认后，编排器继续推进其已授权范围。出现目标冲突、超预算或实质改变时才请求新的决定。

资产母版准备依赖批准剧本及资产规格；正式镜头批量制作依赖批准预演。难点试片应属于有范围和预算的前期验证，实施时显式建模，不能借试片绕过现有正式 run 的 Gate，也不能形成“做预演要先批正式制作”的循环依赖。P1 付费试片之前必须明确适用的前期验证授权路径，固定假设、输入、预算、判据和输出用途；不能等到 P2 才处理。试片可供预演及方法验证，若进入正式成片，仍沿既有用途选择与批准流程办理。

A4 · 审核应该提供可判断的内容

每个审阅包突出：要决定的事情、推荐方案、少量备选、与上版的变化、目标与代价、实际媒体及尚未解决的问题。通过、带明确条件的修订、退回各有具体范围；“看过了”不自动代表批准所有未来版本。条件性意见只授权列明的修改工作；新版本仍须按既有 Gate 获得真实批准，不能继承旧版本批准或自动成为制作基线。

验收依据应与交付内容一致：剧本看人物与表达，资产看实际用途，镜头看动作和可剪性，成片看整体体验。机器检查规格与引用是否完整，专业意见指出理由和位置；审美取舍不由形式校验替代。

专业组织上继续使用现有角色：总编排协调目标、依赖与成本；故事分析／改编／编剧负责原文到剧本；导演和资产角色承担摄影、美术与调度方法；连续性角色连接制作与剪辑；声音、剪辑与审片承担完整声画。新增专业能力先成为这些角色的方法与交付要求，不默认增加一批代理或审批层。

主线 B

质量与效率：在高成本生产前消除关键不确定性

目标是在保持已确认表达与必要质量的前提下，用更少的总时间、总成本得到可用成片。

返工首先作为过程问题调查。前期比较两种表达、试证一个难镜头，是有目标和预算的探索；已知规格未传递、错误参考反复输入、同一失败不断重试、重复确认已解决事项，是应优先消除的浪费。两者分开记账，避免以“零返工”为名取消必要试验或掩盖缺陷。

需要避免的循环

含糊或过载要求进入批量制作
↓
后期集中发现问题
↓
改提示词、全量重生、重新审查

目标机制

明确用途与标准，选择可行方法
↓
难点小样＋局部粗剪
↓
按证据扩大生产或定向修复

B1 · 查明返工发生在哪个环节

环节／原因识别证据解决方向
目标与标准不稳定验收时才新增条件，或不同人要求相互矛盾事前固定必需条件、容差和优化项；需求变更单列成本与影响
改编／分镜不适合当前路线多个动作、精确文字或复杂互动反复无法完成保留表达功能，比较拆镜、换视点、声音表达、合成或其他制作路线
资产与参考不足身份漂移、变体错误、场景关系不稳定先建立必要母版、空间关系与用途；不独立重复生成稳定身份
规格到请求有损失批准要求未进入文字或参考；参考与提示矛盾显示每项必要要求由哪种输入承担，检查覆盖、冲突与过载
模型能力误判接口支持某参数，但实际样片达不到所需控制精度按模型版本与任务条件保存实测证据，先做代表性难点验证
可剪性检查太晚有效动作过晚、余量不足、缺反应镜头或声画不同步按实际使用区间验收，尽早做局部粗剪；将剪辑需求写回制作规格
审查范围不匹配辅助图承担不可能证明的身份要求；同素材同标准反复从头评按实际用途审查；证据不足先改善证据，保持有条件的有效结论
修复与变更范围过大一个局部缺陷触发整镜重生或整场重新审核沿依赖定位受影响项，比较局部修复与重生的总成本及副作用
运行与协作问题额度、提交未知、重复任务、等待授权、版本错配使用已有恢复与幂等机制；明确任务归属、授权范围和在制品上限

原因可以共同存在。缺陷出现的环节不一定是原因产生的环节，原因判断必须附可复核证据。先记录可观察缺陷，原因分别标为已证实、待检验或已排除；针对可能原因设计可比试验，尽量控制其他输入，做不到时说明限制。多项同时修改后成功，只能支持组合方案有效，不能证明其中某一项就是根因。把问题退回最早可修复的责任环节，不把所有失败都交给提示词重写。

B2 · 八项具体机制

  1. 必需条件先确定。例如主角身份、关键道具、可用时长、必要动作和原文表达。偏好优化与必需条件分开，容差结合实际画幅、时长和观看环境定义；已批准要求不能擅自降低。
  2. 资产按用途最小化。先检索已有材料，只准备真实镜头需要的视图、状态和声源。辅助设定图必须说明下游用途；没有用途的四视图、表情包、道具大全不默认生产。
  3. 规格驱动提示词。由固定剧本、资产、状态和镜头意图编译任务，说明每项要求由参考图、文字、音轨或后期承担。保留语义到最终请求的覆盖关系；字数增加不等于控制力增加。
  4. 代表性难点先试。按风险选择人物、手物交互、口型、书写、转场等样本；测试成功后再扩大相同方法的生产。试验先定判据、预算与停止条件。
  5. 滚动完成可看片段。完成一组镜头就进入局部粗剪，及时发现覆盖和节奏问题。按稳定资产／场景组织生成提高复用，同时按成片顺序检查衔接；控制待审核候选数量。
  6. 同类失败及时换方法。按同一逻辑镜头／用途汇总所有新任务和版本，达到约定轮数、预算或改善停滞条件后停止原方法。两轮同类失败可作试点触发值，最终按任务校准；传输重试次数不能代替创作返工次数。
  7. 最小必要修复与复核。先比较保留可用区间、裁切、局部编辑、合成、替换、调整剪辑与重生。新版本检查修改及影响项，并做必要整体副作用检查；未经验证不能保证局部编辑不改变其他区域。
  8. 方法连同失败条件一起复用。把成功和失败关联到任务、模型版本、参考类型与制作条件，形成方法卡及反例。跨情境复验，不把一次成功变为永久默认。

审查证据复用必须同时匹配媒体内容、相关依赖、用途、判据版本与授权范围；每次消费仍检查摘要和依赖有效性。已有结论不能替代新输出的审查，也不能以缓存绕过已批准版本的校验。

B3 · 时间和成本应该如何计算

以“得到一段满足目标的可用内容”为计量对象，分别记录生成用量、主动人工工时和等待时长；货币、请求数、视频秒数等不同单位不混加。缺少实际账单的费用保持未知。估计可以采用区间，并标明依据和不确定性。

指标解释与限制
首次可用率固定规格下首个候选即可满足用途的任务占比；按图／视频／音频和任务难度分组，未知单列

两条主线的接点：一份可交接的制作规格

对一个重要场景或镜头，相关责任人应能快速回答：服务哪个目标；来源与批准版本是什么；观众需要得到什么；人物和环境入出点如何变化；哪些画面与声音承担表达；采用什么制作方法；如何验收；失败后可比较哪些替代；哪些下游会受影响。

按用户最新要求简化

官方更新：检查 → 更新／不更新

用户只做一次选择。版本发现、下载、兼容检查与失败恢复由后台完成，不再增加人工阶段。

检查官方更新显示当前／最新版本与简短变化更新　／　不更新成功或明确失败原因

“更新”按钮就是本次采用授权，选定后直接执行，不再二次询问。“不更新”保留当前版本。无更新显示“已是最新”；检查失败显示原因，不能误报最新。多个官方工具各有更新按钮，也可选择全部更新，并分别显示结果。

拟议 scripts/vsc_provider_sync.py 与后台共用相同实现：只提供检查和更新两个主要动作。复用现有 vendor 发现、差异、固定版本安装能力；当前旧命令 vendor_sync.py --sync 仍只是安装锁定版本，新的入口才负责编排官方更新。

后台只保留必要保障

  • 明确官方来源并记录实际版本；轻量兼容检查自动执行。失败保留旧版，错误集中显示，不让用户逐项审查脚本。
  • 先安装可用的新版本，再切换新任务使用的版本；旧任务继续原版本。初版若不能保留独立环境，则等待受影响在途任务结束后切换，并显示等待原因。
  • 同步不改账号、Key、套餐或超额付费设置；不附带付费生成实测。需要实测时从资源配置页另行触发。
  • 宿主内置工具由宿主管理时显示其更新方式，不承诺脚本能覆盖或回退托管能力。版本更新与模型目录刷新分清楚即可。

现有“真实采用决定”可由这次更新点击满足。实施时统一维护文档中的表述，避免又叠加一个人工审核队列。同步只保留必要记录供排错，日常界面不展示复杂治理流程。该入口尚未实现。

普通用户只需填写名称、供应商／套餐、能力、模型与凭证引用。连接端点、区域、超时、并发及参数覆盖放在高级设置。套餐额度、项目预算与按量消费分别显示；未核实余额显示未知，不能推算成真实剩余额度。

“检查配置”先核对适用字段与当前进程加载状态；只有供应商支持适当的鉴权／发现接口时才提供该项请求检查。“图片试生成／视频试生成／声音试听”单独触发，显示数量、时长和预计用量。不能用文本 hello 测试火山 Agent Plan 多模态凭证，也不能把成功列出模型当作生成权限已通过。

本轮不迁移密钥管理方式；后续若需要在页面输入 Key，再采用独立系统凭证存储并另做实现设计。启停配置只影响新任务分派，保留历史引用；正在运行的任务恢复仍按原配置版本处理。优先复用已有 providers、provider_models、provider_routes 和资源应用接口，扩展多账号、套餐及配置版本时再做必要迁移。

4．第一版交互

  • 自由浏览：空白拖拽平移、滚轮缩放、节点拖拽、适应范围、小地图、搜索定位；媒体预览按点击加载。
  • 范围收敛：沿用左侧结构，按镜头／场显示；展开一层上游或下游，可折叠同批候选与过程节点；“全部项目”先给分组概览。
  • 点击即查：右侧详情复用现有媒体、文案与任务信息；素材列表和画布双向定位，比较操作沿用已有候选比较。
  • 查看影响：突出下游实际引用，显示具体镜头、版本、用料区间及直接／间接关系。替换前评估范围；仍需判断哪些确实要改，不自动全量重做。
  • 保存视图：保存缩放、位置、折叠与筛选。视图布局与正式素材事实分开；拖动和分组不改剧本、用途选择或批准记录。

第一版以自动关系展示、浏览和定位为主。后续可增加从画布登记参考、比较候选、发起局部修复等快捷操作，仍走现有正式接口。手工拖线如有需要，应先选择“参考／候选／备注”等明确含义；备注关系不能冒充生成来源。通用节点编程、任意连线后批量生成暂不纳入本版。

5．与 ComfyUI 的借鉴关系

借鉴节点卡片、带方向的连线、缩放平移、分组收拢、小地图导航以及视图状态保存。VSC 中节点优先表示创作对象、素材、版本和真实生产过程；ComfyUI 的可执行节点图用于控制计算流程。两者可以未来通过任务适配器连接，但不以导入其完整执行引擎作为本次画布前提。

本机 ComfyUI README 明确说明前端已拆分为独立 TS／Vue 项目；安装包 source map 中可查 LiteGraph 的 DragAndScale、LGraphCanvas、LGraphGroup，以及小地图的交互与渲染模块。参考交互机制即可，生产渲染模块保持可替换接缝，不让前端图文件成为新的素材关系权威。具体图形依赖在实施小样后确定，避免为一个页签整体重写当前后台。

7．实施顺序与验收

  1. 资源配置与简化更新：先接现有火山配置、能力筛选、凭证引用、默认用途及检查更新入口；阿里、xAI、OpenAI 可登记待配置状态，通过对应接入验证后才能用于生产。
  2. 画布首版：素材和加工／生成关系、上下游展开、详情定位、缩放拖拽、小地图及视图保存。支持空项目、独立素材、缺失文件。
  3. 返工辅助：补齐文案／规格与时间线关系、版本变化影响、候选比较、复用和局部修复入口。

验收覆盖：点击一次更新即完成流程或明确失败，不再索取重复批准；更新失败保留旧版；配置变更不改旧任务；Key 不进入网页响应与日志；禁止用 Agent Plan Key 测文本；不同项目不串图；一个多输入任务不丢输入用途；布局保存不改生产事实；替换素材可找回实际消费者；历史批准不被画布操作覆盖。

性能以真实项目做基线：首屏只读当前范围和限量节点，媒体使用缩略图；大量候选采用折叠、按需展开与可视区域加载。交付时记录首屏耗时、交互延迟及展开规模，不能用小演示图宣称全项目规模已验证。

只有真实试点证明有价值的记录才固化。优先复用已有契约与角色；新字段须有明确消费者及错误预防用途，没作用的字段和重复步骤应删除。关系与迁移按现有规范验证；全部修改完成后才在最终提交／推送阶段执行一次全量 CI。

专业依据与本方案的推论边界

ScreenSkills 的场记技能说明强调前期剧本与时间拆解、拍摄覆盖、身体与情绪连续性，以及把制作信息交给剪辑。本方案据此加强跨阶段交接，而非照搬大型剧组岗位数量。

ScreenSkills 的视效制作能力说明强调前期规划。VSC 的对应提案是将关键特效与生成路线在扩大生产前试证；这不是对任何具体模型可控性的承诺。

Deming Institute 的PDSA将计划、执行、研究结果与调整连接为学习循环。本方案将其转为事前判据、有限试片、原因分析及条件化方法更新；效率改善仍须实测。

方案编制时内核 doctor 通过。已读相关技能、角色、Profile 与契约；没有运行正式生成、创作试片或全量代码 CI。方案 HTML 完整性检查与专业效果验证分别报告。
